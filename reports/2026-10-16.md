# arXiv 論文トリアージレポート
**対象期間：2026年10月14日〜2026年10月16日**

## 今週の要点
- 文脈工学が「足し合わせるもの」から「行動診断で選ぶもの」に変わった。セマンティックレイヤ/オーケストレーション/圧縮の効果はモデルの行動群（調査型・早押し型・早期離脱型）で符号が入り、最強モデル群には3つすべてが精度を下げる——データエージェント構成の「とりあえず全部盛り」前提が崩れた（2610.20959）。
- 動画生成の制御軸に「時間」が加わった。空間レイアウト・色・カメラ・感情に続き、時相論理仕様で順序・時刻・持続を学習なしでガイドできる（2610.20822）。ただし絶対充足率は46.8%止まりで、時間制御はまだ未解決。
- エージェント記憶の書き込みパスが「フロンティアLLM流用」から「30B級専用モデル」に移行できる見込み（2610.22196）。一方、削除要求への追従困難を測るベンチがまた一本（2610.21405）で、この論点は決着済みとして扱う。
- 会話ボットの検品に「手続きハルシネーション」（発話は正しいが会話の過程を外れる）という新しい検査軸とベンチが登場（2610.21561、MIT公開）。

## S評価（読むべき）
### [セマンティックレイヤーとオントロジー運用] Same Context, Different Agents: A Behavioral Study of Semantic Layers, Orchestration and Compaction in Data Agents
- **arXiv**：[2610.20959](https://arxiv.org/abs/2610.20959) / 2026-10-14 / cs.CL, cs.AI
- **何が新しいか**：従来セマンティックレイヤ・オーケストレーション・圧縮は個別に平均精度で評価されていたが、7LLM×1,514タスク×8構成の統制実験で「CETの効果はエージェントの行動群が決め、強いモデルには3つとも劣化する」ことを示した。調査型（Opus/Sonnet/Astra）はセマンティックレイヤを「答え」として扱い検証をやめ、検証をやめた走行の精度は68%→31%に落ちる。
- **使いどころ**：社内データエージェントの構成判断。早押し型にはオーケストレーション（+23pt、コスト4倍）、早期離脱型にはセマンティックレイヤ（+4.6pt、コスト1.1倍）、調査型にはCET追加なし。工程：分析エージェント運用／指標：精度×ドル/タスク。
- **明日試せる最小検証**：自社データエージェントの直近トレース20本を「ツール実行有無・根拠接地・離脱・反復」で3群に分類（半日）。調査型だった場合、セマンティックレイヤを外して精度とコストを比較するA/B（2日）。
- **落とし穴**：結論は行動群の分類に依存し、新モデルでは再分類が必要。圧縮はプロンプトを小さくしても出力トークンが2.3〜3.5倍になりコスト増。どのCETも最大の失敗原因「見た後の誤データ選択」は直せない。

### [広告クリエイティブ生成] Temporal Specification Guidance for Text-to-Video Generation
- **arXiv**：[2610.20822](https://arxiv.org/abs/2610.20822) / 2026-10-14 / cs.AI, cs.CV
- **何が新しいか**：T2Vの制御は空間レイアウト・色・カメラ・感情の軸で進んできたが、時間軸（順序・時刻・持続）は未整備だった。要求を計量時相論理（MTL）仕様として宣言し、動画-テキストアテンションのトレースを微分可能な充足スコアで評価、その勾配でアテンションをステアする学習なし推論時ガイダンス（TSG）を追加した。分類器もトランスフォーマー逆伝播も不要。
- **使いどころ**：動画クリエイティブ制作の絵コンテ遵守（「商品は後半に登場」「ロゴは常時表示」「3分割の状態遷移」）。5モデル（CogVideoX/Wan系）で仕様充足率+9.5〜20pt、厳密時刻ではTempoControl比でGPUメモリ62%減。工程：動画制作の初稿／指標：仕様充足率・撮り直し率。
- **明日試せる最小検証**：公開モデルWan2.1 1.3Bで「ロゴ常時表示+商品は後半登場」型10プロンプトにTSG（ρ=1・先頭15ステップ）を実装し、CFG比の充足率をVLM判定で比較（2日。擬似コードと設定は附属書にあるが公式コード公開は未確認のため実装込み）。
- **落とし穴**：絶対充足率はベストモデルでも46.8%。効果は状態遷移系が大きく（35%→71%）、3物体の順序入场・重なりハンドオーバー・トリガー応答は平均9〜17%のまま。生成時間1.45〜3.5倍、画質は4モデルで-1.2〜-3.0。時間解像度は潜在フレーム格子が上限。

### [AIの心理学応用] Stop Training Against Soft Users: Mentalized Adversarial Self-Play for Proactive Dialogue
- **arXiv**：[2610.21156](https://arxiv.org/abs/2610.21156) / 2026-10-15
- **要点**：対話ボットは従順すぎるシミュレータ相手に訓練・評価され、soft user biasで楽観的なスコアが出る。BDI潜在状態で相手の心的状態をモデル化した敵対的自己対戦（MASP）で「合理的抵抗への頑健性」を訓練目標にすると、難しいユーザー相手の成功率・合理性制約付き成功率（RCSR）が向上し平均ターン数が減る。
- **使いどころ**：調査・接客ボットの頑健化。既知の「シミュレータ多様性」（2608.12253）に対する「合理的抵抗」ルート。工程：ボット設計／指標：hard-user成功率・平均ターン数。

### [エージェントの長期記憶] Hy-Memory-30B-A3B: Attributed Reinforcement Learning for Long-Term Memory Writing
- **arXiv**：[2610.22196](https://arxiv.org/abs/2610.22196) / 2026-10-15
- **要点**：記憶の書き込みパス（何を残すか・どう表現するか）に汎用フロンティアLLMを置く構成はコストが高く、プロトコル間で転移しない。Mem0/MemOS/Hy-Memoryの3プロトコル横断でOn-Policy蒸留+チャンク帰属RLした30B-A3B専用ライターが、4ハーネス（未学習EverMemOS含む）すべてでOpus 5（54.62%）を上回る55.49%。
- **使いどころ**：エージェント記憶基盤の書き込みコスト削減。フロンティアモデルを書き込みに充てている構成の置き換え候補。工程：エージェント基盤運用／指標：書き込みコスト/タスク×ベンチ精度。Opus比の差0.87ptは薄いので導入前に自社タスクで要検証。

### [エージェント制御] A Responsibility-Centered Coordination Mechanism for Decentralized Multi-Agent Systems
- **arXiv**：[2610.21243](https://arxiv.org/abs/2610.21243) / 2026-10-15
- **要点**：分散協調は委任連鎖で「誰が何に責任を持つか」が曖昧になる。コミットメントで委任に責任を結合し、再帰委任しても上流責任を保持するRCMが、中央集権・分散の両ベースラインを最大+18.7ptで上回り、失敗・危害検出も改善（タスク固有の訓練なし）。
- **使いどころ**：社内マルチエージェント編成の失敗時帰属設計。既知の「ユーザー毎編成の劣化」（2610.00583）・「A2Aの相互確認欠如」（2610.19342）への対応要素。工程：エージェント編成設計／指標：タスク性能×失敗検出率。

### [広告クリエイティブ生成] Decoupled Safety Control: A Safety-Control Algorithm for Training-Free Safety Guidance
- **arXiv**：[2610.21569](https://arxiv.org/abs/2610.21569) / 2026-10-15
- **要点**：学習なしセーフティガイダンスは「避ける対象・現在のunsafe信号・介入内容・介入の継続」を単一のunsafe条件に結合しており、良性と有害の意味が絡む状態で失敗する。介入を現在の生成状態から決める明示的な制御過程に分離（DSC）すると、潜在空間・テキスト空間両方の既存ガイダンスで抑制を強めつつ良性品質を維持する。
- **使いどころ**：セルフホストT2Iパイプラインのブランドセーフティ強化。工程：生成パイプライン検品／指標：不適切内容残存率×良性品質。要旨に定量的結果の記載がなくSにはしなかった（本文で数値確認後に再判断）。

### [エージェント・ハーネス設計] DialFork: Going Beyond Factuality to Evaluate Procedural Hallucination in Conversational Agents
- **arXiv**：[2610.21561](https://arxiv.org/abs/2610.21561) / 2026-10-15
- **要点**：個々の発話が流暢で事実らしくても会話の手続きから外れる「手続きハルシネーション」を測る初ベンチ（36,278対話・24タスク・30人検証）。会話の「展開の仕方」で比較するFlowKL/FlowScoreは意味類似の代替にならず、どのターンで脱線したかの特定も可能。監視・検索・リアルタイムガードレールの3粒度で評価タスクを定義。
- **使いどころ**：接客・面接ボットの検品工程。FlowScore（手続き乖離）を既存の事実性チェックに並列投入。MITライセンスでデータ・コード公開。

### [データ分析] Flexible Doubly Robust Proximal Causal Inference for Censored Outcomes
- **arXiv**：[2610.20893](https://arxiv.org/abs/2610.20893) / 2026-10-14
- **要点**：未測定交絡下で代理変数を使う近接因果推論は、打ち切り生存アウトカムでは制約的なパラメトリックブリッジに依存していた。処置別生存曲線を直接扱う柔軟な二重頑健枠組み（PSB）をカーネル（PSB-K）/ニューラル（PSB-N）の2実装で提供し、無効な代理・重い打ち切り下の頑健性まで評価する。
- **使いどころ**：解約・LTVなどタイミングアウトカムの効果検証で、RCTが組めず代理変数（稼働ログ等）が揃う案件。工程：効果検証／指標：処置別生存曲線の推定。識別前提（代理の妥当性）の審査が先決で採用コストは高い。
