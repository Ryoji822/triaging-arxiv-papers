# arXiv 論文トリアージレポート
**対象期間：2026年8月4日〜2026年8月6日**

## 今週の要点

広告配信の最適化層に生成モデルとエージェントが同時に突っ込んだ週。インセンティブ広告の配分を系列生成問題に定式化し、ラグランジュ乗数を条件にROI制約へ適応する単一ポリシーを学習する GOAL（KDD'26、Kuaishou）と、過去のA/B実験を階層的体験木に構造化して戦略の自動生成・自己進化を行う A/B Agent（Kuaishou、本番でGMV+4.829%）が同時に出た。**どちらも「人間の専門家が繰り返していた調整」を学習対象に置き換えている**。広告運用の自動化を進めているなら、この2本は設計参照として読むべき。

クロス市場クリエイティブでは、VLMが「国名」のような疎な文脈変数を高頻度信号で圧殺する現象（CVE）が Alibaba から報告された。10カ国の実CTRデータで15.75%改善、コード公開、オンラインA/Bテスト済み。**グローバル展開のクリエイティブ自動生成を扱っているなら、このバイアス診断は前提知識になる。**

エージェント側では、ツール選択の誤りを6分類のカナリアツールで診断する手法と、プロンプト注入防御を過去エンカウンターから学習する適応免疫の2本がA評価。ハーネス設計が「固定ルールの適用」から「経験からの学習」に移り始めている。

### [広告クリエイティブ生成] GeoReward: Mitigating Contextual Variable Overestimation in Vision-Language Models for Cross-Market Preference Prediction
- **arXiv**：[2608.04504](https://arxiv.org/abs/2608.04504) / 2026-08-05 / cs.CV
- **何が新しいか**：従来はクロス市場のクリエイティブ予測ミスを「モデルがローカライズに弱い」で括っていたが、本論文は VLM の自己回帰確率連鎖で**高頻度の視覚・テキスト信号が疎な決定変数（国名トークン等）を統計的に溺殺する**メカニズム（CVE）を注意・勾配分析で因果証明し、三重ゲート（検索補強＋視覚変調＋感度損失）で分離した
- **使いどころ**：越境EC・グローバル広告のクリエイティブ判定 × 国別CTR予測精度
- **明日試せる最小検証**：自社のVLMに「同じ商品画像2枚、国名だけ変えた」ペアを10組投げ、回答が国名に連動して変わるか確認する。変わらなければCVEが起きている（**半日**）
- **落とし穴**：MACP データセットは Alibaba の越境ECプラットフォームの実データだが、10カ国・823Kサンプルと偏りがある。自社商材カテゴリでの再検証が必要。CGVM（視覚変調）は Qwen2-VL 依存で、他VLMでの汎用性は未検証

### [データ分析] Generative Optimization for Incentivized Advertising with Global Level Constraints (GOAL)
- **arXiv**：[2608.04421](https://arxiv.org/abs/2608.04421) / 2026-08-05 / cs.LG, cs.AI (KDD'26)
- **何が新しいか**：従来のインセンティブ広告最適化は uplift modeling の二段階パイプラインか、マルコフ性を仮定する offline RL に頼っていたが、本論文は**インセンティブ額を離散ボキャブラリの系列生成に定式化**し、ラグランジュ乗数 λ を条件として広範なROI制約に再学習なしで適応する単一ポリシー（SCPO）を学習した
- **使いどころ**：ポイント還元・クーポン・報酬型広告の配信最適化 × 長期収益・ROI違反率・ユーザ定着
- **明日試せる最小検証**：既存のアップリフトモデルの出力を、インセンティブ額の履歴を条件にした単純な系列生成（上位レンジ・下位レンジの2トークン）に置き換え、ROI制約の境界付近での挙動を比較する（**2日**）
- **落とし穴**：実データ（Kuaishou、約13万DAU・日次184万イベント）は非公開。検証再現には合成環境（Appendix E）を使う必要がある。ボキャブラリ構築（Algorithm 1）がデータの分布依存なので、自社のインセンティブ分布に対して再設計が必要

### [データ分析] A/B Agent: A Self-Evolving Agent for Strategy Iteration in Industrial A/B Testing
- **arXiv**：[2608.04625](https://arxiv.org/abs/2608.04625) / 2026-08-05 / cs.AI
- **何が新しいか**：従来のRAGエージェントは過去実験をフラットに検索していたが、本論文は**歴史戦略を「ドメイン→シナリオ→推薦段階→目的」の階層的体験木に構造化**し、Tree-RAG で文脈一致する証拠を取り出して実行可能な戦略を生成。オンラインA/Bの結果で木を自己更新する閉ループを回す
- **使いどころ**：配信・レコメンドの実験運用 × GMV・ガードレール指標のバランス
- **明日試せる最小検証**：過去3-6ヶ月のA/B実験結果をシートから「シナリオ/段階/目的/戦略/結果/リスク」の行に分解し、新規実験の設計時に似た文脈の過去戦略を手動で引いて比較するプロトタイプを作る（**1週間**）
- **落とし穴**：本番システム（Kuaishou）は GLM-5.1 ベースで、戦略の正確性は GPT-5.5 審査で測っている。LLMの審査員バイアスが出うる。ガードレールの設計はドメイン固有なので、自社指標での再定義が前提

### [エージェント制御] Diagnosing Tool-Selection Reasoning in LLM Agents with Canary Tools
- **arXiv**：[2608.04719](https://arxiv.org/abs/2608.04719) / 2026-08-05 / cs.AI
- **要点**：エージェントが間違ったツールを選ぶ原因を、MCPツールセットに仕込んだ6分類のカナリア（semantic decoys, parameter traps, capability mirages, prerequisite blindness, temporal decoys, granularity traps）で多次元プロファイリングする。8モデル・8,640実行で、capability mirage がフロンティアモデルを一貫して捕らえる一方、他の罠は小モデルでしか発火しないことが分かった。フロンティア層では canary susceptibility rate (CSR) に最大36倍の差。
- **使いどころ**：エージェント導入前のツール選択健全性チェック × 失敗率の帰因分析。カナリアを自社ツールセットに仕込むだけで診断できる。

### [エージェント・ハーネス設計] AgentAntibody: An Adaptive Immune System for Defending LLM Agents against Prompt Injection
- **arXiv**：[2608.04053](https://arxiv.org/abs/2608.04053) / 2026-08-04 / cs.CR, cs.AI
- **要点**：従来のプロンプト注入防御は各タスクを独立問題として扱っていたが、本論文はユーザのセキュリティ境界を**過去のエンカウンターから学習して進化する抗体ライブラリ**として表現する。実行時に脅威を認識して免疫応答を起こし、エンカウンターを跨いで免疫力を強化する。3ベンチ・4バックボーンで、正当なタスク完了を保ったまま既存防御を上回った。
- **使いどころ**：エージェント製品のセキュリティ設計。静的ポリシーから、インシデント経験を蓄積する動的防御への移行根拠として使える。
