# arXiv 論文トリアージレポート
**対象期間：2026年10月26日〜2026年10月28日**

## 今週の要点
- few-step高速生成モデルの隠れコストが定量化された。蒸留による多様性崩壊（ReSeed、FLUX系でDINO多様性+48.3%回復）と不安全生成率の上昇（DICE）で、速度最適化パイプラインの品質・安全盤査が教材つきで可能になった
- MCPツール連携の攻撃面が「ログ記述経由の二次コール」に拡大。正規タスク完了率を下げずにデータを持って出られるため、完了後のホスト側認可が必須
- エージェント基盤の評価軸が「精度」から「決定価値・決定的グレーディング」へ移りつつある。再起動モニタの見かけの利得が再現しない実測、フロンティア未満でのハーネス依存性の実証と、評価方法論の修正が相次ぐ
- A/B分析側は「いつ・誰についての効果か」というestimand定義が符号を変えうるという注意喚起。期間集計単位の事前固定が必要

## S評価（読むべき）
### [広告クリエイティブ生成] A First-Step Bias Restores Lost Diversity in Diffusion Model Distillation
- **arXiv**：[2610.37110](https://arxiv.org/abs/2610.37110) / 2026-10-27 / cs.CV
- **何が新しいか**：従来は多様性の維持を蒸留時に組み込む（GAD/DP-DMD）しかなかったが、蒸留済みfew-stepモデルを凍結したまま、多様性崩壊の発生箇所（軌跡比較で第1ノイズステップ、利得の91%と特定）だけを23万パラメータ（0.002%）のバイアスアダプタで教師の区間平均速度に合わせ、事後修復できる。教師呼び出し・追加ステップなし
- **使いどころ**：クリエイティブ量産工程のバリエーション生成——同プロンプトのアセット重複（探索素材の枯渇）の解消。FLUX系4-stepでDINO多様性+48.3%（教師ギャップの89.8%回復）、FIDも40.22→34.65と改善、推論コスト+0.41%
- **明日試せる最小検証**：稼働中の高速生成（4-step蒸留）と教師モデルで同一プロンプト×25seedを生成し、同プロンプト内のDINOv3埋め込み分散を比較して崩壊を診断（半日）。修復はアダプタ学習8kペアで別途GPU 1-2日
- **落とし穴**：品質トレードオフあり（PickScore -0.7〜-1.5%、HPS -1.5〜-2.8%。動画版では画質0.698→0.675・動き指標劣化と開示）。DINO多様性は実務KPIの代理指標。DMD/DFD系蒸留モデル限定、コード公開は明記なし（プロジェクトページのみ）

### [エージェント・ハーネス設計] kw-bench: Breaking Frontier Harnesses on Real-World Tasks
- **arXiv**：[2610.36405](https://arxiv.org/abs/2610.36405) / 2026-10-26 / cs.AI, cs.SE
- **要点**：監査・デューデリジェンス型の「答えが散在する不完全な証拠から回復する」ナレッジワーク初のベンチ（5年分のVAT再構築、決定的グレーディング）。フロンティア未満のモデルではハーネスが到達距離を決め（OpenCode 0.542 vs ラボ純正ハーネス 0.00）、フロンティア（Opus 5.5）では数週間の業務が22-25分でほぼ満点
- **使いどころ**：調査・リコンサイル系業務のエージェント導入効果の工数試算、およびモデル×ハーネス選定の評価設計（LLMジャッジ不使用の決定的採点）

### [広告クリエイティブ生成] Haste Makes Waste? Towards Safe Few-Step Text-to-Image Models
- **arXiv**：[2610.36665](https://arxiv.org/abs/2610.36665) / 2026-10-27 / cs.CV, cs.CR
- **要点**：few-step蒸留T2Iは教師より不安全生成率が高く、ステップ削減で単調に悪化。既存の概念消去は蒸留モデルで効きにくい（ガイダンスの蒸留方法が起因と診断）。蒸留手法に潜在他空間と保持損失を揃えたDICEでFLUX Schnellの不安全率0.046（従来法≥0.161）
- **使いどころ**：高速生成パイプライン採用時のブランドセーフティ監査——few-stepモデルの安全側前提の確認と消去手法の選定

### [エージェント・ハーネス設計] Log-To-Leak: Prompt Injection Attacks on Tool-Using LLM Agents via the Model Context Protocol
- **arXiv**：[2610.36108](https://arxiv.org/abs/2610.36108) / 2026-10-26 / cs.CR, cs.AI
- **要点**：MCPツールのログ記述が「正規コール完了後の攻撃者制御による別コール」を誘発する二次攻撃面（ASR 62.6-100%、正規タスク完了は±6.6pt以内で共存）。既存防御3種で残留ASR>55%、指示文検出器は良性の85.53%を誤検知
- **使いどころ**：社内MCP導入のセキュリティチェックリスト——最終コール後の二次ツールコールに対するホスト側認可の実装

### [エージェント・ハーネス設計] Monitor Accuracy Isn't the Answer: A Decision-Value Framework for Evaluating AI Agent Restart Monitors
- **arXiv**：[2610.36544](https://arxiv.org/abs/2610.36544) / 2026-10-27 / cs.AI, cs.IR
- **要点**：再起動モニタは精度90%固定でも再試行の残予算成功率により成果が-5pt〜+35ptに振れる（決定価値で評価すべき、Blackwell的十分性基準を適用）。SWE-bench実測では見かけの再起動利得2.29ptは単一の失敗試行由来で、前向きな追試で複製できず103件の生比較0件が認証基準を通過しない
- **使いどころ**：エージェント信頼性ツール（再起動・続行判定）のKPI設計——精度でなく回復機会・決定価値・統計的保証で評価

### [データ分析] Not Just Why, but When and for Whom: Revisiting Common Estimands in Causal Inference
- **arXiv**：[2610.36084](https://arxiv.org/abs/2610.36084) / 2026-10-26 / stat.ME
- **要点**：処置効果は同一単位・同一標本でも時間・反復・測定方法・固有確率性で変動し、estimand（いつ・誰についての効果か）の取り方次第で符号が割りうる。単一RCTデータでも、観測されない非交絡への前提が推定値と被覆率を左右する
- **使いどころ**：A/Bテストの読み出し設計——効果の期間・集計単位・対象の定義を事前固定し、符号解釈の前提を明示
