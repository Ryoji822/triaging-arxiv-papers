# arXiv 論文トリアージレポート
**対象期間：2026年8月23日〜2026年8月25日**

## 今週の要点
- エージェント安全の主戦場が「単発アクションの拒否」から「データフローの宣言的ポリシー」へ移動した。AgentFlow はフロー規約+SMT検証で侵害0%を utility 向上と両立させ、従来の「強制は utility を数ポイント犠牲にする」前提（既知: APC）を崩した。
- text-to-SQL では検索ハーネスのチューニングより「過去クエリ履歴から文脈アーティファクト（SQLリファレンスカード）を構築する」側が2倍以上効くという内部本番規模の証拠（Beyond the Harness）。効果は使用ログの存在に依存。
- ツールを多く積んだエージェントのキャッシュ前提矛盾（ツール一覧変更→プリフィックス失効）をリクエスト構造の分離で解く CacheRouter は、入力コスト1/8〜1/12という即効性のあるレバー。
- 記憶系は書き込み側の刈り込み・検索経験の償却・単一対話からの注入攻撃と、「コストと安全性」の運用論に研究が集中している。

## S評価（読むべき）
### [エージェント・ハーネス設計] AgentFlow: A Flow-Centric Policy Language and Framework for Securing LLM Agent Systems
- **arXiv**：[2608.22868](https://arxiv.org/abs/2608.22868) / 2026-08-24 / cs.CR
- **何が新しいか**：従来の実行時強制は個々の権限チェック単位で越権を止める代わりに utility を8.6-13.9pt失わせていた（既知: APCの委任連鎖追跡）。AgentFlow は「どの機微データがどのツール・委譲先・出力先に流れてよいか」をラベル付きランタイムエッジの宣言的ポリシー言語に書き、参照モニタと有界SMT検証で強制する。AgentDojo 949件で侵害33.0%→0.0%かつ utility 46.7%→63.3%と**向上**、AgentDyn 200件でも73.5%→0.0%で utility はほぼ不変（44.5→43.5%）。
- **使いどころ**：社内エージェントがクライアントデータ（個人情報・機密）に触れる開発・運用工程。指標は侵害率（インシデント数）とタスク完了率。
- **明日試せる最小検証**：運用中エージェント1本の実行トレースに「PII/機密ラベル→外部ツール・外部宛先エッジ禁止」のフロールールを紙上適用し、違反エッジを数える（半日〜2日、ツールはトレースとスプレッドシートで足りる）。
- **落とし穴**：コード未公開で参照モニタは自作が必要。utility 向上は「注入に従ってタスクを壊していたぶんが戻った」ベンチ特性の可能性があり自社タスクでは平坦と想定すべき。policy-visible な行動のみが対象で、モデル内部への漏えいは止めない。著者自身が結果を preliminary と限定。

## A評価（目を通す）
### [セマンティックレイヤーとオントロジー運用] Beyond the Harness: End-to-End Optimization of Context Artifacts for Enterprise Text-to-SQL
- **arXiv**：[2608.22830](https://arxiv.org/abs/2608.22830) / 2026-08-24 / cs.AI（COLM 2026 ワークショップ）
- **要点**：社内 text-to-SQL のボトルネックはモデルでも検索でもなく「モデルが受け取る文脈」。過去クエリプロファイルを再利用可能な SQL リファレンスカードに蒸留する文脈アーティファクト最適化が、大規模ネット小売の本番5176クエリで AST 類似度12-25%改善（検索ハーネス側の最適化は3-12%）。
- **使いどころ**：社内分析・レポーティングエージェントの text-to-SQL 精度向上（工程: 分析・レポート、指標: クエリ正答率・分析工数）。履歴ログの蓄積が前提。公開ベンチ BEAVER では p=0.12 と非有意で、効果は本番使用ログに依存する点を承認の上で採用する。

### [エージェント制御] CacheRouter: A Dual-Path Tool Routing Architecture with Cache-Preserving Main-Model Isolation for Long-Tail Tool Discovery
- **arXiv**：[2608.22708](https://arxiv.org/abs/2608.22708) / 2026-08-24 / cs.AI
- **要点**：ツールの段階的開示（progressive disclosure）は可視ツール一覧が変わるたびにキャッシュプリフィックスを失効させる。ツール選択を独立したルーティングチャネル（サブモデルが全ツール群から検索・選択・実行）に分離し主モデルのプリフィックスを固定すれば、トークン単位キャッシュヒット率91-95%、入力コストは1/8〜1/12。
- **使いどころ**：ツール数が多い社内エージェントの入力コスト削減（工程: エージェント運用、指標: 入力トークンコスト）。評価がプロトタイプ55クエリ+30ターン会話と小規模なので、本番投入前に自社トレースでヒット率を再計測する。

### [広告クリエイティブ生成] Direct, Parallel, or Sequential? A Comparative Study of Training-Free Multi-Subject Image-to-Video Generation
- **arXiv**：[2608.22819](https://arxiv.org/abs/2608.22819) / 2026-08-24 / cs.CV
- **要点**：学習なしマルチ被写体 I2V の3パラダイム（一括生成/並列分解合成/逐次追加）を、被写体保持・運動忠実度・時間整合・被写体間干渉で系統比較。並列は各生成の難度を下げるが被写体間文脈が弱く、逐次（背景先行）は蓄積文脈を保つが順序依存と誤差伝播が残る、と失敗モードが構造的に分かれる。
- **使いどころ**：商品+人物など複数被写体動画の制作初手でパラダイムを選定する打ち分け表（工程: クリエイティブ制作、指標: リテイク率・被写体一致）。学習不要・公開モデルで再現可能。
