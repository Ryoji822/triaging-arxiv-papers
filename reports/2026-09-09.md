# arXiv 論文トリアージレポート
**対象期間：2026年09月07日〜2026年09月09日**

## 今週の要点
- LLMによる人間置換の評価軸が「忠実度」から「統計的置換可能性」へ移った。デジタルツインは平均効果は再現するが「誰が平均と違うか」の情報をほぼ持たず、行動忠実度は置換の必要条件でも十分条件でもない。アンケート削減の判断基準が変わる（S評価）。
- 人間のAIレビュー支援で、好まれる推論表現（plan・分解型）と実際に検証を支える表現（単純なCoT）が乖離。検収UIの形式選定に直接効く知見。
- A/B分析の共変量調整について「調整しない/予後変量/インバランス補正」の3処方箋が ex-post bias の単一基準に統一。
- エージェント記憶は権限と喪失の計測が主戦場に。エビクションの不可逆損失を分離する監査法、生体認証による本人性担保。
- ハーネス進化とモデル微調整の干渉が特定された。進化済みハーネス下での完全軌跡模倣は逆効果で、失敗ターンのみ書き直すon-policy修正で両立。

## S評価（読むべき）
### [マーケティング調査] When Can LLM Digital Twins Reduce Human Measurement? From Behavioral Fidelity to Statistical Substitutability
- **arXiv**：[2609.07987](https://arxiv.org/abs/2609.07987) / 2026-09-07 / cs.AI, stat.AP
- **何が新しいか**：既知の silicon sampling 評価は「忠実度・分散圧縮の測定」（2608.14079, 2608.18265）だったが、これは置換判断の基準自体を定式化した。mixed-subject design と prediction-powered inference を土台に「統計的置換可能性」を4次元（集合的忠実度・ペアレベル信号・有限サンプル人間ラベル回復・母集団間安定性）で評価。2つの実証評価・複数モデル・複数応答者表現で、ツインは平均効果を再現するが個人差の情報をほぼ持たず、新しいモデルでも人間データの節約に確実につながらないことを示した。
- **使いどころ**：調査工程 — アンケート・概念テストのサンプル一部置換の可否判断。調査コスト・フィールド期間の指標で効く。結論は「平均効果の推定なら置換余地、セグメント差・個人差の推定なら不可」という使い分けになる。
- **明日試せる最小検証**：既存調査データ（n≥300、平均効果とセグメント差が既知のもの）でツイン予測を混ぜたPPI推定を回し、人間ラベルを何%削っても信頼区間が維持されるかを1推定対象で確認（2日）。
- **落とし穴**：置換可能性は推定対象（estimand）ごとに決まり一律の「ツイン可否」はない。個人差情報の欠如はセグメント分析（広告実務の主用途）を直撃する。CC-BYだがコード公開の明記なし。

### [AIの心理学応用] Do Reasoning Representations Help Humans Evaluate LLM Outputs?
- **arXiv**：[2609.09038](https://arxiv.org/abs/2609.09038) / 2026-09-08 / cs.LG, cs.HC（EMNLP 2026 Findings）
- **要点**：6種の推論表現形式を統制した人間実験で比較すると、参加者は plan・分解型を好むが、実際の検証・信頼・解釈を支えるのは単純なCoT。好まれる表現は正しいトレースへの誤警報を増やし、検証意欲が低いのに高信頼というキャリブレーションリスクを持ち込む。
- **使いどころ**：AI生成物の検収・レビュー工程 — 推論過程を人に見せるUIの形式選定。誤警報率・レビュー精度で効く。

### [データ分析] Covariate Adjustment in Randomized Experiments: A Unified Framework for Decision and Practice
- **arXiv**：[2609.09039](https://arxiv.org/abs/2609.09039) / 2026-09-08 / stat.ME, econ.EM, stat.AP
- **要点**：共変量調整の3処方箋（調整しない／予後変量で調整／インバランス補正）を統一し、最適修正は ex-post bias で、調整の唯一の基準は ex-post bias への予後性だと示す。インバランス補正と精度改善は同じ意思決定問題の両面であり、既知の調整推定量を回復する理論的正当化を与える。
- **使いどころ**：A/Bテストの設計・分析工程 — どの共変量で調整するかの実務指針。MDE・検出力の改善。

### [エージェントの長期記憶] What Eviction Destroys: A Restore-Counterfactual Audit of Forgetting in Agent Memory
- **arXiv**：[2609.08279](https://arxiv.org/abs/2609.08279) / 2026-09-08 / cs.CL, cs.AI, cs.DB
- **要点**：記憶エビクションの損失を「復元反実仮想」（金証拠を読み込み文脈に再注入し同じリーダーで再実行）で、回復可能な検索失敗と不可逆的喪失に分離。80kトークン予算で不可逆率0.60-0.73、8kで全ポリシー1.00。精度一致比較ではポリシー間差を検出せず、予算-精度フロンティアは検索レジームを報告しないと比較不能。
- **使いどころ**：パーソナルエージェントの記憶設計 — 何を圧縮・削除してよいかの判断と、記憶システム検収の指標（不可逆損失率）。

### [エージェントの長期記憶] Personalizing LLM Agent Memory Using Biometrics（Bio-Memory）
- **arXiv**：[2609.08558](https://arxiv.org/abs/2609.08558) / 2026-09-08 / cs.AI
- **要点**：共有エージェントの記憶検索を意味類似だけでなく生体照合の候補プール形成で制御。10ユーザー共有設定・7顔/10掌プロトコルで所有者と非所有者クエリをF1/BLEUで最大27pt分離。既知の権限ラベル（2608.01679）と違い、権限を物理本人に結合する。
- **使いどころ**：多人数共有のパーソナルアシスタント運用 — 記憶の越権応答防止。家庭・店舗端末での本人性担保。

### [エージェント・ハーネス設計] Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails
- **arXiv**：[2609.09134](https://arxiv.org/abs/2609.09134) / 2026-09-08 / cs.AI
- **要点**：7つのエンタープライズエージェントタスクで、進化済みハーネス下で専門家の完全軌跡による模倣学習は全タスクで4-30pt劣化（未進化ハーネス下では有効）。弱いモデルが実行能力なしに専門家の計画戦略を採用し、ハーネスとの適合を壊すため。失敗ターンのみ専門家が書き直すon-policy修正（メタレベルMLEエージェントで自動化）でハーネス進化とモデル適応の利得を両立。
- **使いどころ**：社内エージェントの低コスト化（小モデル＋ハーネス）— 蒸留の失敗条件と処方。成功率あたりコストの削減。

### [広告クリエイティブ生成] LoGAN: Multilingual Font Localization with Generative Agents
- **arXiv**：[2609.07029](https://arxiv.org/abs/2609.07029) / 2026-09-07 / cs.CV, cs.AI
- **要点**：多言語フォントローカライズを、グリフ拡散＋スタイル適応＋スペーシング/カーニング転送＋テクスチャ拡張のVLMエージェント協調に分解。数枚のグリフから全文字セットを生成し、27言語（CJK含む）のフォント・実ロゴでFLUX/Nano-Banana等をグリフ忠実度とスタイル一貫性で上回る。
- **使いどころ**：グローバルキャンペーンの制作工程 — ブランドフォント・ロゴの多言語展開の制作工数削減。
