# arXiv 論文トリアージレポート
**対象期間：2026年10月21日〜2026年10月23日**

## 今週の要点
- 合成消費者の主戦場が「アンケート回答」から「店内の視覚的購買行動」に移った。TwinStore（S評価）はVLMショッパーにレンダリングされた棚を見せて購入を決めさせ、未見の801世帯の実購入データの自然変動に迫り、価格弾力性も実測範囲に収まる。棚割り・価格・パッケージの事前スクリーニングが一人で回せる水準（ただしライセンスは非商用限定）。
- その前提として、LLMの社会的認知は「信念は99%認識しても行動予測は29%」という乖離が定量化された（ToM gap）。シミュレーション消費者を使う調査は「信念理解」スコアを行動予測の代理にできない。
- 効果検証側では、段階導入パネルの推定対象が「導入時点で1回防ぐ」と「全期間禁止する」の2つに分裂し、既存のDiD/合成統制は後者に答えられないことが整理された。
- エージェント運用では、複合ポリシーを述語プログラムにコンパイルする構成が安価モデルでフロンティア級の精度と判定の安定性を両立（SCOPE）。
- 人の側では、AI執筆にメタ認知足場を挟むRCTで「成果は上がるが主観的な楽さは下がる」productive friction が確認された。AI活用研修の設計原則になる。

## S評価（読むべき）
### [マーケティング調査] TwinStore: A Synthetic Consumer Platform Using Vision--Language Models
- **arXiv**：[2610.30909](https://arxiv.org/abs/2610.30909) / 2026-10-22 / cs.AI
- **何が新しいか**：従来のsilicon samplingは回答分布の再現が限界で、実購買データに対する検証を欠いていた。TwinStoreはショッパーがVLMで棚を「見て」購入を決め、未見の801世帯のレシートに対してカテゴリミックスのJSダイバージェンス0.017–0.018（世帯自身の自然ドリフト0.012）まで迫る。価格弾力性−0.78〜−1.60は実測範囲内、販促リフト1.25–1.7倍（実測1.4倍）、3つの決定モデル（Claude/Qwen/GPT系）で一致。同一ショッパー・乱数固定のペア設計でA/B比較の分散を削減できる。
- **使いどころ**：調査工程の事前スクリーニング——棚割り・価格・パッケージ・販促POPのA/B、コンジョイント、レイアウト最適化。指標は売上・客単価・衝動買いシェア・弾力性。実店舗実験の前段の絞り込みとして、検証コストと期間を圧縮する。
- **明日試せる最小検証**：GitHub（BrainJellyPie/twinstore）からインストールし、携帯で撮った実店舗の棚写真1枚をプラングラム化 → Shelf Lab で価格変更1件の反実仮想を合成ショッパーに見せて選択シェアの変化を確認（半日。ローカルモデルでAPI課金なしで起動可）。
- **落とし穴**：ライセンスはTwinStore License 1.0（研究・非商用限定）——クライアントワークへの商用利用は交渉要、社内評価目的に限る。検証は米スーパーマーケット1形式で、来店頻度を動かす介入は未検証。ショッパーはモデルの知識・バイアスを継承する（既知のsilicon sampling限界、台帳2609.07987）。実店舗テストの代替ではない。

## A評価（目を通す）
### [AIの心理学応用] Diagnosing the Explicit-to-Applied Theory of Mind Gap in LLMs
- **arXiv**：[2610.31060](https://arxiv.org/abs/2610.31060) / 2026-10-22 / cs.AI
- **要点**：ToMベンチの集計スコアは「信念を認識する能力（explicit）」と「その信念を行動予測に使う能力（applied）」を混同する。Llama-3.1-8BはSimpleToMで認識99.4%なのに行動予測28.9%。構造化リマインダーで大部分が回復し、weight更新（BSTTT）は+1.3〜5.5pt止まり。分解報告と回復可能性の介入比較を推奨。
- **使いどころ**：LLMペルソナ・シミュレーション消費者を使う調査の品質管理——「信念理解」のスコアを行動予測の代理に使わず、認識と行動予測を分けて測る。

### [同僚としてのエージェント] Metacognitive Scaffolds Create Productive Friction for AI-Assisted Knowledge Work
- **arXiv**：[2610.30945](https://arxiv.org/abs/2610.30945) / 2026-10-22 / cs.HC, cs.AI
- **要点**：AI支援執筆のRCT（297人・594エッセイ）。目標明確化とタスク分解のメタ認知足場は成果物品質を上げ、効果は足場除去後も持続し3日後のトピック想起も改善。一方で参加者はAIを「より役に立たない・より負担」と評価——主観的な楽さが支援の価値を過小評価する。
- **使いどころ**：社内AI活用研修とブリーフ設計——入力の楽さを追求するほど品質が下がる箇所に、目標明確化・分解の足場を挟む。指標は成果物品質とスキル定着。

### [データ分析] Causal inference in staggered adoption panels: The correct comparison set depends on your intervention
- **arXiv**：[2610.31537](https://arxiv.org/abs/2610.31537) / 2026-10-22 / stat.AP, econ.EM
- **要点**：段階導入パネルでDiD・マッチング・合成統制が暗黙に答える「導入時点で1回防いだら」介入と、「測定時まで全期間導入を禁じたなら」介入は別の推定対象。後者には時間変化する比較セットと時間変化する重みが必要で、既存の共通手法は原理的に答えられない。
- **使いどころ**：地域段階ロールアウト施策（キャンペーン・機能導入）の効果検証——分析前に「遅延シナリオ」と「不実施シナリオ」のどちらの推定対象かを確定し、比較セットを選ぶ。

### [エージェント・ハーネス設計] SCOPE: Compiling Natural-Language Policies into Neurosymbolic Predicate Programs
- **arXiv**：[2610.31062](https://arxiv.org/abs/2610.31062) / 2026-10-22 / cs.AI, cs.CL
- **要点**：複合自然言語ポリシーを小モデルのニューラル述語＋決定的抽出器＋合成コードの実行プログラムにコンパイルし、敵対的反例生成でプログラムと学習データを共同最適化。最弱の実行器で最適化したプログラムは他モデルにそのまま転移し、安価なモデルでフロンティア級の精度・安定した判定・判定根拠は述語出力から解釈可能。
- **使いどころ**：社内エージェントのコンプライアンス層——ポリシー遵守判定を単発LLM judgeから置き換え、判定コストと揺らぎを下げる。台帳2610.12292（決定的ルールとLLMトリアージ分離）の「複合ポリシーでどうやるか」への答え。
