# arXiv 論文トリアージレポート
**対象期間：2026年10月25日〜2026年10月27日**

## 今週の要点
- エージェントの「コンテキスト経済」の評価基準が変わった。軌跡の削減・圧縮はトークン数を減らしても、キャッシュ前提の課金では42構成中0件が節約にならず逆に高コスト化する（2610.35496）。一方、圧縮のタイミングと内容をモデル自身に管理させるとフロンティアモデルでコスト-34%が成立する（2610.34425）。文脈管理の判断は「トークン数」でなく「実課金」で行うべき段階に入った。
- 営業・販促エージェントの規律測定に新しい枠組み。規則を「言える」こと（静的準拠90〜99%）と圧力下で「準拠行動を取れる」こと（3〜17%）が別物であることを同一ポリシー原子のペア設計で分離示した（2610.34185）。導入判定はルール試験でなく committed action で。
- 生成広告の収益設計が動き始めた。1枚の生成画像で複数広告主が露出を競う形態を、制御可能生成＋クリック意図評価＋インセンティブ両立オークションの統合框架として定式化（2610.34917）。
- A/Bテストの比率KPI（ROAS等）は分子・分母を個別に回帰調整すると効率を落とす。統合2ステップ推定で検出力を上げられる（2610.35666）。

### [エージェント制御] R2A-Sales: A Policy-Atom-Matched Benchmark for Rule-to-Action Gaps in Goal-Directed Sales Agents
- **arXiv**：[2610.34185](https://arxiv.org/abs/2610.34185) / 2026-10-25 / cs.AI
- **何が新しいか**：従来のエージェント評価は静的なポリシー質問かタスク成功率で、両者をつなぐ測定がなかった。本論文は同じポリシー原子（規則・事実・証拠・行動制約・ツール契約）を静的プローブと多ターン営業シナリオで共用する matched 設計にし、「ルールを言える」（K=89.9〜99.1%）と「圧力下で準拠行動を取れる」（A=3.0〜17.3%）のギャップ80.4〜92.5ptを分離測定した。コード所有の台帳でコミット済み行動だけを採点し、主張だけの行動に得点を与えない。
- **使いどころ**：営業・販促エージェントのリリース判定工程 × コンプライアンス違反率（景表法・規制文言・ブランドセーフティ）。静的試験だけでGoを出す運用を止める根拠になる。
- **明日試せる最小検証**：自社販促エージェントの規制文言10個を抜き出し、(1)静的質問 (2)商圧（ノルマ・競合）をかけた多ターンシナリオ のペア10組を作って両方実行し、KとAの差を測る（2日、プロンプトと台帳スクリプトのみで実装可）。
- **落とし穴**：中国語圏3ドメイン・24ポリシー原子限定で日本語・広告領域への転移は未検証。Aは「安全な終了」も要求するためGは上限評価（実際のギャップはこれより小さい可能性）。プロンプトだけの改善はどの指標も支配しなかった。

### [エージェント・ハーネス設計] The Hidden Costs of Forgetting: A Study of Trajectory Deletion in Software Engineering Agents
- **arXiv**：[2610.35496](https://arxiv.org/abs/2610.35496) / 2026-10-26 / cs.SE
- **何が新しいか**：従来は「軌跡の75%を削っても成功率は保たれる」（AgentDiet）とされ、削減＝コスト削減の前提で文脈圧縮が設計されてきた。9,400実行・42構成の統制実験で、(1)削除は遅延必須（即時削除は19/42構成で有意に劣化）、(2)削られた内容は再取得で補償され再取得率は最大7.5〜10.6倍、(3)キャッシュ前提課金では42構成中0件が節約で26構成が有意に高コスト（最悪約5倍）——を示した。本文 Table II で裏付け済み。
- **使いどころ**：エージェント運用 × トークン実コスト。軌跡トリミング・文脈圧縮ツールの導入判断を「トークン削減数」から「キャッシュ前提の実課金」でやり直す。
- **明日試せる最小検証**：手元のエージェントの直近10タスク分の利用ログを、キャッシュ単価（例: 入力1: キャッシュ0.1: 出力5）で再計算し、圧縮・トリミング設定あり/なしの実コストを比較する（半日）。
- **落とし穴**：モデルは DeepSeek-V4-Flash 1種・2エージェント（Mini-SWE-agent, Trae）限定でモデル依存性は未検証。キャッシュ単価比0.1・「全マッチングプレフィックスがキャッシュヒットする」という楽観的前提（実コストは下限見積り）。SWE領域の挙動で他ドメインは未測定。再現パッケージ公開。

### [エージェント・ハーネス設計] CTXAgent - Self-Controlled Context Management of LLM Agents
- **arXiv**：[2610.34425](https://arxiv.org/abs/2610.34425) / 2026-10-25 / cs.AI
- **何が新しいか**：文脈圧縮は「ハーネス側がトークン閾値で発動する」のが定説で、直近の知見はオープンモデルは自己管理できないだった。ツール2つ＋指針1段落だけ与えてモデル自身に「いつ圧縮するか・何を残すか・どう引き継ぐか」を委ねると、フロンティア7モデルの大半が自己管理して live context を100k以下に保ち、Claude Opus 5.5 では Claude Code と同成功率のままコスト-34%（明示的200k窓構成比）/-49%（デフォルト比）を実現した。窓サイズという運用パラメータ自体を消せる。エージェント・ベンチ・全結果行を公開。
- **使いどころ**：長期セッションのエージェント運用 × コストと成功率維持。ハーネスの閾値調整・窓サイズ管理の工数をモデル側に移す構成判断。
- **明日試せる最小検証**：公開 agent を混在セッション（35ターン以上、複数タスク横断）で1〜2日動かし、live context・実コスト・ standing instructions の保持を既定ハーネスと比較する（2日）。
- **落とし穴**：自己管理が成立するのはフロンティアモデル中心でオープンモデルは従前どおり不可。圧縮頻度が高すぎるモデルは他のコストが増えて効果がモデル間で大きくばらつく。plant facts・一時観察の保持は決定論的チェック済みだが自社ワークフローでの検証は別途必要。

### [データ分析] Regression Adjustment for Ratios of Treatment Effects in Randomized Experiments
- **arXiv**：[2610.35666](https://arxiv.org/abs/2610.35666) / 2026-10-26 / econ.EM, stat.ME
- **要点**：ROAS・CVR/CPA 比 etc. の「処置効果の比」をA/Bテストで推定する際、分子と分母を個別に回帰調整する既存手法は効率ターゲットを外す。比に対応する変換結果変数を直接予測する2ステップ推定＋クロスフィッティングを提案し、高次元共変量・正則化予測でも最終調整は固定次元で安定。スパース性不要（共変量数＞サンプル数も可）の持久性理論と漸近効率の保証付き。
- **使いどころ**：A/Bテスト分析 × 比率KPIの検出力向上（必要サンプル削減）。実験設計チームの標準処理チェックリストに加える候補。

### [エージェントの長期記憶] Agent Memory as Recommendation: Recommender-System Design for Long-Term Memory of LLM Agents
- **arXiv**：[2610.34673](https://arxiv.org/abs/2610.34673) / 2026-10-26 / cs.IR, cs.AI, cs.CL
- **要点**：永続エージェントの記憶選択（何を文脈窓に入れるか）を予算付きスレート推薦として定式化し、推薦システムのカスケード（候補生成→ランク学習→スレート構成）を適用。書き込み・検索ともLLM呼び出しゼロで、LongMemEval のマルチセッション質問で A-Mem・HippoRAG 2 等に+10〜31pt、クエリ毎64呼び出しのLLMリランカーと3.2倍安いサーブコストで互角。利得の源泉は「証拠が揃ったスレート」の完備性に分解して特定。
- **使いどころ**：永続エージェントの記憶配信 × 精度とサーブコスト。LLM呼び出し型の記憶整理を推薦パイプラインで置き換える設計の根拠。

### [広告クリエイティブ生成] DiffAuction: An Auction-Driven Framework for Generative Image Advertising
- **arXiv**：[2610.34917](https://arxiv.org/abs/2610.34917) / 2026-10-26 / cs.CV
- **要点**：1枚の生成画像に複数広告主の商品を露出させる生成広告を、学習不要の残差シェア較正による制御可能生成＋クリック意図（CTI）評価器（VLM+LLM、10訓練アノテータ・1000画像で検証）＋DSIC/IRを保証する学習型アフィンマキマイザーオークションの統合框架に定式化。目標シェアとCTIの単調関係を既存手法より強めた。
- **使いどころ**：広告商品・収益設計 × プラットフォーム売上・クリック意図。生成型広告在庫の価格付けを検討する際のたたき台。

### [エージェント・ハーネス設計] Rethinking Verification in Agent Harnesses
- **arXiv**：[2610.34577](https://arxiv.org/abs/2610.34577) / 2026-10-25 / cs.AI
- **要点**：検証をエージェントライフサイクルの4層（初期指示・実行中リマインダ・完了ゲート・独立レビュー）に分解し、17設計×7フロンティアモデルを Terminal-Bench / SWE-bench と新規 VisualBench で比較。独立レビューが精度+5.9〜9.5ptをコスト1.13〜1.25倍で達成し最良のトレードオフ。完了ゲートは効果が大きいがコスト増も大きく、指示・リマインダはモデル依存の小幅改善。
- **使いどころ**：社内エージェントの品質設計 × 精度/コスト比。まず独立レビュー層を足す判断の根拠。

### [広告クリエイティブ生成] VibeVideoBench: Evaluating Multimodal Agents on Code-Driven Video Generation
- **arXiv**：[2610.35864](https://arxiv.org/abs/2610.35864) / 2026-10-26 / cs.CV
- **要点**：拡散モデルでなく「コードで毎フレームを描き音を合成する」エージェント動画生成の初ベンチ（239課題・12カテゴリ・9システム・2,151ロールアウト・人間の盲検選好で検証）。GPT-6 Astra と Claude Opus 5.5 がリードするが、最高システムでも約4分の1の課題で核心要件を落とす。未納品の4分の3は能力不足でなく、レンダリング開始の遅れ・低速・未実行という運用要因。
- **使いどころ**：データストーリー・解説動画などの制作トライアル × 納品成功率・制作工数。ツール選定とタイムアウト／レンダ予約の設計資料。
