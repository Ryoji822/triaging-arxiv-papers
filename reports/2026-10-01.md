# arXiv 論文トリアージレポート
**対象期間：2026年9月29日〜2026年10月1日**

## 今週の要点
- エージェントのガバナンス論点が「何を許可するか」から「許可したものが承認どおりに実行されているか」へ移った。Approval Laundering は、人間が承認したコマンドAとハーネスが実際に実行するA'が黙って置き換わる失敗を6分類で系統化し、Claude Code のフック計装による反復実験で「承認＝実行」の前提が体系的に破れることを示した。
- GEO（生成エンジン最適化）の測定単位が単一回答から会話軌跡へ。早期に引用されたソースが複利で再引用される「conversational capture」が形式化され、単一ターン評価の順位が会話軌跡では当てにならない（Kendall τ=0.4）と指摘された。
- シリコンサンプリングは「出力の限界指摘」（分散圧殺・信念更新破綻）から「入力（ペルソナ種）を経験研究で接地する」段階へ（MetaPersona。効果はタスクまちまち）。
- 広告クリエイティブ生成枠は長尺化・蒸留・部分改良の積み重ねが中心で、新しい測定軸は心的状態→行動ベンチ（MindWorldBench）程度。ハーネス進化系論文は乱造気味で差分のないものは切り捨てた。

### [エージェント・ハーネス設計] Approval Laundering: Systematizing Approval–Execution Binding Failures in AI Coding-Agent Harnesses
- **arXiv**：[2609.38983](https://arxiv.org/abs/2609.38983) / 2026-09-30 / cs.CR, cs.AI, cs.SE
- **何が新しいか**：既知の認可研究（権限のセッション固定 2608.15888、認可階層整理 2609.15906）は「どの権限を与え、どこで強制するか」を扱ってきたが、本論文は「人間が承認した行動Aとハーネスが実行する行動A'の同一性」（credential-binding integrity）を初めて系統化した。Scope・Argument・Temporal・Tool・Delegation・Semantic の6分類の置き換え失敗を、Claude Code の PreToolUse を計装したヘッドレス反復実験（各N=19-20、Wilson信頼区間、評定者一致κ=1.0）で再現性をもって示す。
- **使いどころ**：コーディングエージェント導入時のセキュリティ監査（運用工程）。承認ゲート通過後の越権実行率（Bound-Gap Rate）の検出・是正。
- **明日試せる最小検証**：Claude Code の PreToolUse フックで「承認時に表示されたコマンド列」と「実際に dispatch されたコマンド列」の差分を10タスク分ログに取り、6分類のどれに該当するか（パスの絞り直し=Scope、引数書き換え=Argument 等）を分類集計する。**工数：1日**。
- **落とし穴**：提案する Approval Token（キー付きケイパビリティ）は Delegation/Temporal laundering は消除（p<10^-5）するが、Scope/Argument には設計上効かない＝フィールドだけ見る検証では捕まらない置き換えが残る（正直なネガティブ結果として報告）。単一著者・コード公開の明記なし。防御はツール呼び出し境界でのバインディングに限る点も限界。

### [マーケティング調査] Conversational Capture: A Trajectory-Level Framework for Evaluating Generative Engine Optimization in Multi-turn Human-Agent Interaction
- **arXiv**：[2609.40069](https://arxiv.org/abs/2609.40069) / 2026-09-30 / cs.HC, cs.IR（HAI '26 採録）
- **何が新しいか**：GEO の評価は「1質問→1回答での引用可視性」が暗黙の単位だったが、本論文は回答がユーザの信念を変え→次の質問が変わり→検索が変わる閉ループを二層系として形式化し、早期引用ソースが再引用されやすくなる「conversational capture」（機械側の履歴条件付け検索＋人間側の被捕捉ソースへのフォローアップ）を定義。Pólya壺理論で「単一ターン評価ではフィードバック項が必ずゼロになる」ことを証明し、累積可視性が会話長に対して超線形に成長することを示した。
- **使いどころ**：GEO・LLM検索対策の効果測定設計（調査・運用工程）。単発の引用率でなく会話軌跡での累積引用獲得・capture 係数をKPIにする再設計。
- **明日試せる最小検証**：自社商材カテゴリの質問10本を起点に、LLM API でフォローアップを含む5〜10ターンの会話を20シミュレーションし、初ターンで引用されたソースが以後のターンで引用され続ける率（capture 係数の粗い代理）と単発引用率の順位相関を取る。**工数：1日**。
- **落とし穴**：数値（feedback項>direct項、compounding ratio>2、τ=0.4）は理論とモデル導出の例示であり、実回答エンジン・実ユーザでの実証ではない。コード・データの公開明記なし（9p・2図2表）。採用判断は自社計測が前提。

### [エージェントの長期記憶] When Correct Memory Goes Wrong: Fuzzing Persistent Memory Use in LLM Agents
- **arXiv**：[2609.38275](https://arxiv.org/abs/2609.38275) / 2026-09-29
- **要点**：記憶の事故研究はポイズニング・扁平化・権限崩壊と「内容の誤り」を扱ってきたが、本論文は「正しい記憶が誤った使われ方をする」失敗（クエリ起因・記憶状態起因の2型）を、メモリチェックポイントをシードに変異義務付きでクエリ/状態を変異させるファジング（U-Fuzz）で系統発見する。複数の記憶システム・ベースラインを一貫して上回り、API越しに最終応答しか観測できない設定でも探索が有効。
- **使いどころ**：エージェント記憶システムのリグレッションテスト・QA 設計。リリース前の記憶誤用パターンの摘出（運用工程、潜在障害検出数）。

### [マーケティング調査] MetaPersona: Task-Grounded Synthetic Populations from Empirical Social Science
- **arXiv**：[2609.38392](https://arxiv.org/abs/2609.38392) / 2026-09-29
- **要点**：シリコンサンプリングのペルソナ種には「どの属性を入れ、どう値を割り当てるか」の原理がない（cold-start）。11,000+の実証研究を注釈した MetaPersona-DB からタスク関連エビデンスを検索し、文献由来の依存グラフと経験的事前分布で合成人口を構成する。誤情報信念・AIツール感情で有効、所得再分配は mixed、ペルソナ構築コストは1タスク$0.5未満。既知の「silicon sampling は分散を圧殺する／平均しか再現しない」（2608.14079, 2609.07987）への入力側からの答え。
- **使いどころ**：シリコンサンプリング調査の設計（調査工程、合成人口の母体再現性・調査前工程质量）。

### [広告クリエイティブ生成] MindWorldBench: Evaluating Mental-State-to-Behavior Reasoning in Image-to-Video Generation
- **arXiv**：[2609.39147](https://arxiv.org/abs/2609.39147) / 2026-09-30
- **要点**：I2V評価は物理的整合・視覚品質が主で、信念・欲望・知覚が行動を駆動する「心的状態→行動」推論は未測定だった。mental-state-conditioned な動画生成を評価する初のベンチ。2607.27201（心的状態を持つ世界モデル）が測ったのは人の意思決定予測で、生成側の測定はこれが初めて。
- **使いどころ**：ナラティブ映像・ペルソナ演技の生成評価軸候補（クリエイティブ評価工程）。ただし直近の実務需要は限定。
