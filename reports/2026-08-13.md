# arXiv 論文トリアージレポート
**対象期間：2026年8月11日〜2026年8月13日**

## 今週の要点
動画生成の品質制御が「職人のプロンプト/シード総当たり」から**閉ループ最適化**へ変わる兆し。I2V モデルを学習不要・モデル不問のラッパーで包み、mLLM によるプロンプト自己改良（DSG/CMQ）と seed/CFG のベイズ最適化を回すことで human preference 最大 69% まで引き上げた（Beyond Trial-and-Error）。エンタープライズ AI の実態が、ChatGPT Enterprise のアカウント級データ（1,500組織・1,700万メッセージ・公開企業財務と結合）で初めて定量的に浮かんだ——導入は大型・R&D/SG&A 集約的企業に偏り、早期キャリア層の利用強度が突出（How Organizations Use AI）。ハーネス設計では、ツールの「能力」ではなく「界面の組織化」だけでコーディングエージェントの効率が最大 4.7 倍動くことを 11,700 軌跡の統制実験で示した（Devil Is in the Interface）。また LLM を研究ワークフローに載せる前提が崩れた——撤回/偽造/疑似科学論文 42 本への engagement は 95%、30 モデル全滅で、拒絶は一部の悪名高い話題に集中＝堅牢な認識能力ではなく話題キーの安全フィルタ（TRACES）。

## S評価（読むべき）
### [広告クリエイティブ生成] Beyond Trial-and-Error: Agentic Optimization for Image-to-Video Adherence
- **arXiv**：[2608.12290](https://arxiv.org/abs/2608.12290) / 2026-08-12 / cs.CV, cs.AI, cs.MM
- **何が新しいか**：従来は I2V の品質がプロンプト/シード/CFG の職人的な総当たりで決まっていたが、生成パラメータ空間の探索そのものを閉ループ最適化問題に再定式化した。第1段階で mLLM が Davidsonian Scene Graph（DSG）クエリで意味忠実度を、Common Mistake Questions（CMQ）でアーティファクトを自動評価してプロンプトを反復改良し、第2段階で seed と CFG をベイズ最適化で共最適化する。両者を統合する新指標 Video-Text Adherence（VTA）を導入し、任意のブラックボックス I2V に学習不要で被せる。
- **使いどころ**：クリエイティブ制作工程の動画生成パート。主指標はプロンプト忠実度（VTA）と手戻り工数、副次として human preference 勝率。既存の I2V（Runway/Kling 等）の上に乗るレイヤーで、モデル買い替えなしで効く。
- **明日試せる最小検証**：既存 I2V モデル1つに (1) DSG ベースのプロンプト自己改良ループ、(2) Optuna 等による seed/CFG のベイズ最適化を挟み、10 プロンプトで VTA と無ガイド生成を比較する。**工数：2日**（DSG クエリ生成と BO ラッパーの実装。モデル自体には触れない）。
- **落とし穴**：69% は"up to"（最大値）で、ベースラインは「無ガイド生成」。既に職人が最適化している現場では差が縮む。BO の試行回数ぶん I2V 推論コストが線形に増え、品質向上≠コスト削減。DSG/CMQ 評価器自身の精度が新しいボトルネックになる。公開コードは見当たらず（CC-BY・TeX ソースのみ）、DSG/BO は既存手法の再実装になる。

## A評価（目を通す）
### [同僚としてのエージェント] How Organizations Use AI: Evidence from ChatGPT
- **arXiv**：[2608.12236](https://arxiv.org/abs/2608.12236) / 2026-08-12 / econ.GN, cs.AI, cs.HC
- **要点**：ChatGPT Enterprise のアカウント級レコードを利用ログ・役職・タスク分類・公開企業財務と結合し（2026年3月まで、6か月時点で 1,500 組織超・1,700万メッセージ超）、プライバシーを保ったまま4つの事実を示した。(1) 利用は新規採用と既存採用者の強度増の両方で急成長、(2) 米国上場企業では大型・高価値・R&D/SG&A 集約的企業に集中、(3) 採用企業内では職能・階層をまたぐが早期キャリア層の強度が突出、(4) 書く・技術・伝達・情報統合の幅広い知識労務に及ぶ。
- **使いどころ**：戦略／新規営業工程。AI 成熟度の高い業種・企業規模をターゲットに AI 関連サービスとポジショニングを設計し、自社クライアント群へ外押しする判断材料。導入が「実験」から「知識労務の基盤」に移行していることの定量根拠。

### [エージェント・ハーネス設計] The Devil Is in the Interface: Evaluating How Tool Architecture Shapes Coding Agent Behavior
- **arXiv**：[2608.11386](https://arxiv.org/abs/2608.11386) / 2026-08-11 / cs.SE
- **要点**：コーディングエージェントでツールの「能力」を同じに保ったまま「界面の組織化（tool architecture）」だけを6種比較した（リポジトリ級 issue 修正、3アクタ・11,700 軌跡）。bash 単体比で、構造化低位インターフェースは再現安定性 4.7 倍、自然言語検索は関連ファイル到達 +11%、Python CodeAct 系はステップ -41.6%・トークン -56.3% を達成。一方、中間推論を記録させるような軽量テキスト足場は行動への効果が限定的だった。
- **使いどころ**：運用／社内自動化エージェントの開発工程。指標はトークン・ステップ・タスク成功率。ツールを「追加する」のではなく CodeAct 系に「組織化し直す」ことで、モデルを変えずにコストと安定性を両立できる。

### [同僚としてのエージェント] TRACES: A Benchmark for Epistemic Reliability in Scientific Reasoning by LLMs
- **arXiv**：[2608.11415](https://arxiv.org/abs/2608.11415) / 2026-08-11 / cs.IR, cs.AI
- **要点**：LLM を科学ワークフローに載せる前提（信頼できる文献を選別できる）を初めて直接測るため、撤回・偽造・疑似科学の42論文を探針とした。30モデル・10反復で、不当前提への engagement は非空応答の95%、全モデルがプローブの71%超で失敗し22モデルは90%超。拒絶はごく一部の悪名高い話題に集中し、マッチ構造統制下で消える＝堅牢な認識能力ではなく話題キーの安全フィルタにすぎない。
- **使いどころ**：調査／戦略工程で LLM に市場・文献調査を任せる前工程。出典の撤回/信頼性チェックを必須ゲートとして組み込む設計根拠になり、「ハルシネーション」より根の深い認識信頼性の欠陥を前提条件に組み込める。
