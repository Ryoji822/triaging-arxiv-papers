# arXiv 論文トリアージレポート
**対象期間：2026年8月12日〜2026年8月14日**

## 今週の要点
AIチャットボットの「開示」に関する事前登録実験（n=1,500）が、規制論に直結する不都合な事実を出した——「AIであること」の開示は説得効果をほぼ変えない（12.6→13.1pt）が、「何を狙っているか」の開示は効果を半減させる（6.3pt）。現行のAIラベル規制は"何であるか"に固執し"何をしようとしているか"を見落としている（Toward Meaningful Transparency）。広告配分のオフライン評価でも、前提が揺らいでいる。頻繁に使うtop-k決定ルールのオフポリシー評価は、弱いオーバーラップの下では推定量の選択以前に「ロガーとターゲットの行動一致度」で支えが決まり、クロスフィッティングでは optimizer's curse が消えない——実務者が持つ単一ログ内で有効サンプルサイズの閾値は転移しない（When Can You Trust Offline Evaluation）。生成系では、T2Vの空間配置制御を勾配計算不要の閉形式解で実現し推論オーバーヘッドを最小化する手法（GATO-Vid）と、アニメキャラクターの著作物性を除去しつつ画質を保つIPコンプライアンス向け手法（Erase but Preserve）が揃った。ユーザーシミュレータを1本のLLMに固定するとモード崩壊で実ユーザーに全く汎化しないことが理論・実験・人実験で示され、シミュレータ多様化が解答になる（One Frozen Simulator Is Not Enough）。

### [AIの心理学応用] Toward Meaningful Transparency for AI Chatbots: Disclosing Persuasive Intent Reduces Persuasion
- **arXiv**：[2608.11794](https://arxiv.org/abs/2608.11794) / 2026-08-12 / cs.CY, cs.AI, cs.HC
- **何が新しいか**：従来のAI開示研究は「AIであること」を伝える効果を測っていたが、説得ボットを1,500名・60政策テーマで実験した結果、AI身元開示だけでは説得効果が無開示と同等（13.1pt vs 12.6pt）だったのに対し、説得意図と手口の開示を添えると効果がほぼ半減（6.3pt）し、参加者がキャンペーン手法を否定的に評価し罰則強化を支持するようになることを示した。「システムが何であるか」でなく「何をしようとしているか」の開示が効く。
- **使いどころ**：ブランドコミュニケーション／ステルスマーケティング対応工程。AIチャットボットを用いたキャンペーンの設計と法務・ブランドセーフティ判定。指標は説得効果（brand lift）とブランド信頼感、および景表法・ステマ規制への適合性。
- **明日試せる最小検証**：既存のチャットボットキャンペーン1件について、入口メッセージに「AIである」旨と「説得を試みる」旨の2段階の開示をA/Bで出し分け、エンゲージメント・転換・離脱の3指標を1週間比較する。**工数：半日**（メッセージ文案変更のみ。ボット側は変更不要）。
- **落とし穴**：効果半減は「説得が効かなくなった」だけであり、キャンペーンKPIそのものを下げる方向に働く。政治的テーマ（60政策問題）で測っているため、商業ブランドへのそのままの外挿は限界がある。英国成人限定で地域差・文化差は未検証。開示文の文言そのものが効果を左右するため、T2の文言をそのまま使わず自社法務で精査すること。

### [データ分析] When Can You Trust Offline Evaluation of Equal-Cost Top-k Allocation? A Controlled, Reproducible Benchmark and Practitioner's Guide
- **arXiv**：[2608.12489](https://arxiv.org/abs/2608.12489) / 2026-08-12 / cs.LG, stat.ME, stat.ML
- **何が新しいか**：従来のOPE研究はログの「鋭さ」がオーバーラップを決めると暗黙に想定されていたが、決定的top-kルール（配分率100%の実務で最も頻繁な配置）では、サポートを決めるのはロガーがターゲットと同じ行動をどれだけ取ったかであって、ターゲット自身のスコアでロガーを鋭くしてもオーバーラップはほぼ動かない。さらに、クロスフィッティングでナイサンスを分離しても optimizer's curse は残り、推定傾向の誤差がIPSを破壊する一方でDRはほぼ不変、という3つの実務的失敗モードを制御再現可能なベンチで分離した。
- **使いどころ**：運用／データサイエンス工程。配分予算の下でターゲティングルールをデプロイする前のオフライン評価。指標はOPE推定の信頼性・ROI予測の乖離。6推定量×5データセット×2効果掃引で、実務者が手元の単一ログで「どの推定量をいつ信用できるか」の判断材料になる。
- **明日試せる最小検証**：手元の配分ログ1本について、現在使用しているOPE推定量の推定値を (1) ロガーとターゲットの行動一致度、(2) policy-level honest splitting の2点で診断し、現行のクロスフィッティングのみの評価に reuse bias が残っていないか確認する。**工数：2日**（ベンチ公開コードを社内ログ構造に合わせてラップ）。
- **落とし穴**：合成ログ・傾向下限0.02の設定なので、極端に稀な行動や無制限の重みを持つ実ログでは挙動が異なる可能性がある。有効サンプルサイズの閾値は「ログをまたいで転移しない」ことが本文で明示されており、他社の閾値を流用できない。単一著者・380KBとコンパクトだが、ベンチはpublic data onlyで公開済み。

### [広告クリエイティブ生成] Erase but Preserve: Controllable Removal of Copyrighted Animation Characters via Optimized Semantic Anchors
- **arXiv**：[2608.12806](https://arxiv.org/abs/2608.12806) / 2026-08-13 / cs.CV, cs.AI
- **要点**：T2I拡散モデルがアニメキャラクターを無断再現する著作権リスクに対し、モデルの連続的テキスト表現上で最適化したアンカー埋め込みをキャラクターの代理として設定し、構造制約付き適応戦略で対象埋め込みを置き換える。従来の概念除去が多様で特徴的なキャラクターに適合しなかったのに対し、除去度合いを連続制御でき、多対象除去・モデル転移・他手法へのplug-and-play強化を備える。
- **使いどころ**：クリエイティブ制作・法務工程。生成広告に既存IPが混入するリスクの低減。指標は著作権リスクと画質維持率。最適化アンカーは既存のモデル修正系手法に被せて性能を上げられる。

### [広告クリエイティブ生成] Spatially-Grounded Text-to-Video Generation via Inference-Time Gradient-Free Optimization (GATO-Vid)
- **arXiv**：[2608.13037](https://arxiv.org/abs/2608.13037) / 2026-08-13 / cs.CV
- **要点**：T2Vで「指定位置に指定物を置く」空間制御を、勾配ベース最適化の計算コストなしで実現する。代替クロスアテンションスコアを解析的に閉形式で解き、トランスフォーマの潜在多様体に合わせたon-the-fly注入機構で挟む。学習不要・勾配不要で、ローカライズ精度で既存の学習不要ベースラインを一貫して上回り、計算オーバーヘッドは最小。
- **使いどころ**：クリエイティブ制作工程のT2Vパート。ブランドロゴ・商品を動画内の指定位置に配置する際の制作工数と手戻り回数。既存のT2Vモデル（Runway/Kling等）の上に乗せるレイヤーで、モデル買い替えなしで効く。

### [AIの心理学応用] One Frozen Simulator Is Not Enough: Simulator Collapse in Multi-Agent RL
- **arXiv**：[2608.12253](https://arxiv.org/abs/2608.12253) / 2026-08-12 / cs.CL, cs.AI, cs.LG
- **要点**：人-AI相互作用のMARLで1本のLLMをユーザーシミュレータにすると、シミュレータがモード崩壊しているためポリシーが狭い戦略に過学習し、未見シミュレータや実ユーザーに汎化しない（simulator collapse）ことを理論付けた。推論時のVerbalized Samplingで+9%、訓練時の集団Co-Trainingで+14%（人実験でも追認）。SCOPEフレームワークを公開。
- **使いどころ**：運用／テスト工程。チャットボットキャンペーンの事前検証でユーザーシミュレータを1本に絞っている設計を見直す。指標は実ユーザーへの汎化成功率。シミュレータの多様性がポリシーの多様性と同じくらい重要であることが示される。
