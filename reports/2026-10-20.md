# arXiv 論文トリアージレポート
**対象期間：2026年10月18日〜2026年10月20日**

## 今週の要点
- パーソナライズド動画広告で「事前制作在庫からの検索」をやめ「ユーザー単位の生成」に置き換えた本番A/B（快手 MAPS、ARPU +9.85%）が初出。クリエイティブ在庫が最適化の制約だった時代が終わりつつある。
- エージェント実運用系の主戦場が「文脈・記憶の副作用の計測」に移っている。ツール出力の検索読みによる証拠置換（-8〜11pt）、再観測不能な状態の喪失、記憶による応答多様性の圧縮（エントロピー-34.7%）、記憶経由の資格情報越権と、失敗の解剖学が揃ってきた。
- 安全・ガードレール評価の相対性を示す工業データが出た。ベンチスコアの23倍差がラベル定義の違いだけで生じており、ベンダースコアの鵜呑みが危険になる。
- 生成モデル基盤側は成熟期。マルチショット3D制御・長尺drift補正・物理整合ベンチと改善は続くが、パラダイムを動かす話ではなく総じてB止まり。

## S評価（読むべき）
### [広告クリエイティブ生成] MAPS: A Multi-Agent Personalized Script-Driven Video Advertising System Enhanced by Reinforcement Learning
- **arXiv**：[2610.25748](https://arxiv.org/abs/2610.25748) / 2026-10-19 / cs.IR
- **何が新しいか**：従来のパーソナライズド動画広告は事前制作したクリエイティブ在庫からの検索（DLRM/GRM）だったが、プロフィール→脚本→合成→フィードバック帰属の4エージェント閉ループ（脚本生成はGRPO＋構造/嗜好/商品整合の3軸報酬）でユーザー単位にネイティブ広告を生成し、Kuaishou本番A/Bで vs GRM CTR+2.87%/CVR+2.74%/ARPU+9.85%、vs DLRM ARPU+12.89%を達成。ARPUの利得がCTRを上回り、在庫制約の解除が収益構造自体を変えることを示している
- **使いどころ**：動画広告の制作・配信工程。CTR/CVR/ARPUと制作リードタイム。少量制作×検索の前提で組んだ現行のパーソナライズ設計を見直す根拠になる
- **明日試せる最小検証**：既存動画広告脚本10本を対象に、ユーザープロファイル条件付きのプロンプト生成（学習なし）と現行脚本をLLMジャッジ2軸（嗜好整合・商品整合）で盲検採点し、差が出るか確認（2日）
- **落とし穴**：本番検証はKuaishouの「特定シナリオ」限定で全プラットフォーム展開ではない。動画合成が内製Kling-Omni依存・コード非公開で再現は不可。オフライン指標はLLMジャッジ。ユーザー単位の広告生成は景表法・ステルス広告規制と表示規約の法務確認が前提

### [データ分析] Next Best Action: Causal Constrained Offline RL for Business Action Targeting
- **arXiv**：[2610.26817](https://arxiv.org/abs/2610.26817) / 2026-10-19 / cs.LG
- **要点**：CRMのNext Best Action（クーポン・ライフサイクル施策の選択）を制約付きMDPに定式化し、オフポリシー因果補正をLP解に統合。影価格から予算・公平性制約の経済トレードオフが読める。ライドシェアクーポンでLTV +19%（vs 行動ポリシー）/+8%（vs 短視的ベースライン）
- **使いどころ**：CRM施策配分の意思決定モジュール設計。LTV・制約充足率。2608.10182のuplift+制約付き配分に対し、MDP定式化と影価格による解釈性が新しい答え。ただしOPEのみでオンライン検証なし・アクション空間は2値

### [エージェント・ハーネス設計] Policy Is Not Capability: Some Safety Benchmarks Measure Which Definition of "Unsafe" You Trained On
- **arXiv**：[2610.25060](https://arxiv.org/abs/2610.25060) / 2026-10-18 / cs.LG
- **要点**：同一約53kプロンプトを2つの運用定義（「有害要求か」「モデレーターがブロックするか」）でラベルし直した10アームの工業実験で、ベンチスコアが定義だけで0.043〜0.99の23倍差。パラメータの0.03%で全レンジを移動させられる。しかも訓練プールに有名ベンチの82〜88%が混入していた
- **使いどころ**：モデレーション/ブランドセーフティ分類器の選定・調達。ベンダーベンチスコアを自社ポリシー定義のラベルで再検証するチェックリスト化（混入・ラベル定義・教師由来の3点確認）

### [エージェントの長期記憶] Whose Credential Is It? How Owner Attribution in Agent Memory Shapes Cross-User Account Misuse
- **arXiv**：[2610.25707](https://arxiv.org/abs/2610.25707) / 2026-10-19 / cs.AI
- **要点**：共有記憶からの他人の資格情報は、プロンプトに到達しても（exposure）ほとんど行動化しない。ただし記憶が単一の外来資格情報を「本人の記録」として提示する条件では7エージェント中80〜94%がそれを使用し、被害者のアカウントを最大43%変更。資格情報の行に所有者名を書いておくと305対中92→1に激減（クリーンな記憶で3〜5タスクのコスト）
- **使いどころ**：顧客対応等の共有エージェント記憶スキーマ設計。越権アクション率。記憶に保存する資格・ID類に所有者属性を必須にする設計レビュー（半日）

### [エージェント・ハーネス設計] Same Simulation, Different Evidence: Where Retrieved Tool Output Costs LLM Agents Accuracy
- **arXiv**：[2610.26836](https://arxiv.org/abs/2610.26836) / 2026-10-19 / cs.AI
- **要点**：長大なツール出力（84万字）をファイル保存して検索読みさせる文脈管理は、シミュレーションが同じでもGPT系で-8〜11ptの「証拠置換」（レポートを読まず自己の出力ファイルから誤丸めで答える）を起こす。Claude系では検出不能。出力ファイルのどれが権威かを明示するだけで+6〜8pt回復
- **使いどころ**：エージェントの文脈管理・プロンプト設計。正答率・再試行コスト。長大ツール出力を扱うハーネスの指示文に「権威出力」の指定を入れる変更（半日）

### [エージェントの長期記憶] Remembering Has a Price: Learning Memory Worth under Resource Constraints
- **arXiv**：[2610.26453](https://arxiv.org/abs/2610.26453) / 2026-10-19 / cs.AI
- **要点**：生成・相互作用・記憶の予算が厳しい設定では、既存の洗練された生涯記憶手法が単純検索や記憶なしと大差なくなる。実行フィードバックから「どの経験を残す価値があるか」を学び、保持と検索に一貫適用するTokenWorthが最少トークンで最高成功率。コード公開
- **使いどころ**：長期運用エージェントの記憶コスト設計。成功率あたりトークン。2609.34227（予算で記憶戦略が逆転）を agent 側の実装に落とした形

### [AIの心理学応用] A Thousand Faces: A Persuasion Benchmark with Experience-Grounded Persuadees Informed by Psychology and Pragmatics
- **arXiv**：[2610.25206](https://arxiv.org/abs/2610.25206) / 2026-10-18 / cs.CL
- **要点**：説得ベンチのペルソナは信念・欲望の列挙では不十分で、経験→判断→表現→修正理由の接地があるとき説得は難しくなり、供給された個人的理由の活用とペルソナ忠実度が向上する。1,000ペルソナ・9ドメイン、データ公開
- **使いどころ**：メッセージ・訴求の事前検証に使うシミュレーション被験者の品質設計。説得予測の妥当性。シリコンサンプリングの既知限界（2609.15849等）に対する被験者側の改善策
