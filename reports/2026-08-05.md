# arXiv 論文トリアージレポート
**対象期間：2026年8月3日〜2026年8月5日**

## 今週の要点

エージェント記憶が「保存できるか」から**「どの権限で再利用してよいか」**の問題に移った週。統合時に出典の権限が消える現象（authority collapse）が7×7=49構成のうち48で観測され、越権実行率50.3%という数字が出た。同時に、個々は無害に見える記憶を積んで有害挙動を誘発する共謀型ポイズニングが OpenClaw 上で攻撃成功率75%を記録している。**記憶機能を入れているなら、今週はここを見るべき。**

画像生成側では、レイアウト指示の失敗原因が「参照枠の曖昧さ」に切り分けられた。22モデル横断で、対象物の向きを基準にした指示は画面座標基準より平均41.8ポイント精度が落ちる。プロンプト規約で回避できる話なので実務に即効性がある。

## S評価（読むべき）

### [エージェントの長期記憶] When Memory Becomes Authority: Benchmarking Authority Collapse at the Memory Consolidation Boundary
- **arXiv**：[2608.01679](https://arxiv.org/abs/2608.01679) / 2026-08-03 / cs.AI
- **何が新しいか**：従来の記憶研究は「何を覚えるか」を問うていたが、本論文は統合の瞬間に**出典の権限（ユーザー事実か／観測か／常設指示か）が消える**ことを独立した障害として定式化し、主張を固定して権限だけを変える対照ペアで測った
- **使いどころ**：社内エージェントへの記憶機能の導入審査 × 越権実行率
- **明日試せる最小検証**：既存の記憶レコードに「出典権限」列を1つ足すだけの版を作り、越権が起きる10ケースで前後比較する（**半日**）
- **落とし穴**：権限ラベルの自動予測は 16.9%→0.0% と効いているが統制環境の数字。誤って厳しく付くと業務側が止まる。論文は benign task success がほぼ不変と報告しているが、自社タスクでの確認は別途必要

### [エージェントの長期記憶] Salami Attack: Stealthy Collusive Memory Poisoning against OpenClaw
- **arXiv**：[2608.01637](https://arxiv.org/abs/2608.01637) / 2026-08-03 / cs.AI
- **何が新しいか**：従来の記憶ポイズニングは1件の悪性レコードを検出する前提だったが、本論文は**個々は無害に見える断片を積み上げて結合時に有害化させる**共謀型を自動生成し、記憶希釈と記憶レベル防御の両方を貫通させた
- **使いどころ**：エージェント運用のセキュリティ設計・レッドチーム × 攻撃成功率
- **明日試せる最小検証**：自分のエージェントの記憶ストアを1つ選び、良性に見える断片を手で3件仕込んで意図した挙動が出るか確認する（**半日**）
- **落とし穴**：評価対象は OpenClaw、2バックボーン48シナリオ。ASR 75.0% / 記憶保存率81.3%は「最も保存されやすい設定」での上限値で、保存が保守的な構成では下がる。攻撃側の再現には fine-tuned generator が必要

### [広告クリエイティブ生成] Can Text-to-Image Models Draw from the Right Frame of Reference?
- **arXiv**：[2608.03357](https://arxiv.org/abs/2608.03357) / 2026-08-04 / cs.CV
- **何が新しいか**：従来のT2Iレイアウト評価は失敗を「空間指示に弱い」で括っていたが、本論文は**画面座標基準と対象物の向き基準の指示を1,200対で分離**し、後者だけで22モデル平均41.8ポイント落ちることを示した
- **使いどころ**：バナー・キービジュアル制作のプロンプト規約 × リテイク回数／制作工数
- **明日試せる最小検証**：既存プロンプトの方向表現を洗い出し、「画面の左」のように視点基準へ統一する1行ルールを制作ガイドに入れて、次の10案でリテイク数を比較する（**半日**）
- **落とし穴**：論文の緩和策（VLMゲート書き換え）は 25.0%→29.2% と弱く、最良モデルでも FoR 精度44.3%。**モデル側の改善を待つ前提で計画を立てないこと**。当面はプロンプト規約で回避する運用になる

### [エージェント・ハーネス設計] Harness-R1: Learning to Edit Executable Runtime Harnesses from Agent Failure Trajectories
- **arXiv**：[2608.02276](https://arxiv.org/abs/2608.02276) / 2026-08-03
- **要点**：失敗軌跡をまとめて実行可能なハーネスパッチに変換する9Bの「ハーネス技師」を、実際のタスク成功率を報酬にオンラインRLで訓練する。WebShop/ALFWorld/DBBench で 44.3%→53.6%、対象エージェントをFT後もさらに 59.2%→64.2%。
- **使いどころ**：エージェント運用の失敗ログを、モデル差し替えではなくハーネス改修に還流させる根拠として使える（RL訓練が必要なので、手で真似るのは「失敗をバッチで束ねて直す」という運用手順の方）。

### [データ分析] Causal Inference with Unstructured Outcomes
- **arXiv**：[2608.03085](https://arxiv.org/abs/2608.03085) / 2026-08-04
- **要点**：テキストや画像そのものを結果変数にすると平均処置効果が定義できない問題に対し、処置で最も変化した特徴を学習で取り出す MCF（maximally contrasting feature）を提案。識別条件と推定アルゴリズム、共変量による異質効果まで整備している。
- **使いどころ**：自由回答アンケートや制作物そのものを結果変数にした効果検証（例：生成AI導入で制作物の内容がどう変わったか）。ただし手法論文で実装コストがあるため、着手は検証設計フェーズから。

### [広告クリエイティブ生成] CultureVidBench: Benchmarking Cultural Understanding in Text-to-Video Generation
- **arXiv**：[2608.01942](https://arxiv.org/abs/2608.01942) / 2026-08-03
- **要点**：12カ国・8文化圏・14の文化側面をカバーする1,000プロンプトで、7つのT2Vモデルを人手評価とMLLM自動評価にかけた。意味的整合と画質は高いのに、儀礼・可視テキスト・音の文化的細部は落ちる（特に低リソース地域）。
- **使いどころ**：海外／インバウンド向け動画の生成物チェックリストとして、MLLM自動評価の軸をそのまま流用できる。

### [広告クリエイティブ生成] CAPE-T2V: Captioner-Anchored Prompt Enhancement toward Two-Sided Conditioning Alignment
- **arXiv**：[2608.03046](https://arxiv.org/abs/2608.03046) / 2026-08-04
- **要点**：T2V の学習時キャプションと推論時のプロンプト書き換えのズレを、スキーマ共有だけでは解消できない問題として扱い、キャプショナを基準にした両側整合を提案。
- **使いどころ**：動画生成の初稿品質を、モデル差し替えではなくプロンプト強化器側の設計で上げる方向の裏付け。

### [エージェントの長期記憶] MutMem: Cryptographically Authorized Mutation in Persistent Agent Memory
- **arXiv**：[2608.02843](https://arxiv.org/abs/2608.02843) / 2026-08-03
- **要点**：記憶は後の結果で書き換わるべきだが、可変な検索重みは「認可された更新」と「改ざん」の区別を失わせる。署名付きの正負エビデンスを残す認可付き変更プロトコルを提案。
- **使いどころ**：記憶を持つエージェントの監査要件を満たす設計（誰の権限でその記憶が変わったかを説明できる状態にする）。

### [エージェントの長期記憶] LeanMem: Simple and Efficient Long-Term Memory for LLM Agents
- **arXiv**：[2608.03463](https://arxiv.org/abs/2608.03463) / 2026-08-04
- **要点**：既存の記憶システムは異種の対話内容を一律の要約・検索パイプラインに流すため、トークンを食うか細部を不可逆に失うかの二択になる。内容の型ごとに扱いを分ける。
- **使いどころ**：長期運用エージェントのトークンコスト削減。設計が単純なので自前実装の比較対象にしやすい。

### [データ分析] Confidence Horizons
- **arXiv**：[2608.03889](https://arxiv.org/abs/2608.03889) / 2026-08-04
- **要点**：anytime-valid 推論は無限の時間軸で有効性を保つ代償として保守的になる。実務では予算や倫理でホライズンに上限があるので、その前提でよりシャープな境界が取れるかを問う。
- **使いどころ**：A/Bテストの逐次モニタリングと早期停止。テスト期間に上限がある通常の広告案件はまさにこの設定に当たる。
