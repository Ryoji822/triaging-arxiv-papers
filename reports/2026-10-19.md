## 今週の要点
- **人物表現のリスクが定量化**：T2I美化バイアスの初の大規模監査（27生成器・51,300顔+事前登録採用実験）が、美化を指示しなくても生成顔が実顔を上回り、実人物の評価まで下げることを示した（S）。AI人物素材の検収基準が「ステレオタイプ」から「美化・人種偏り」へ広がる。
- **オープン重みのテキスト/レイアウト生成が実用域へ**：5Bスクラッチ学習で長文テキスト96.3%再現（MOSS-Image、S）。ただし英・中のみで日本語は未検証——日本語バナーでの最小検証が採否の分水嶺。
- **エージェント運用の安全論点が「設定」から「重み・承認・利得測定」へ**：重み自体をトロイ化するDNS exfil（S）、承認済みallowルールの権限昇格（A）、MCPゲートウェイ設計差の初ベンチ（A）、ハーネス最適化利得の平均54%が過学習（A）。
- **記憶の「関連→十分」クラスタが今週4本**（TIDER/MemCompile/QEMem/JointCore）。台帳2610.09348で主張は確立済みで差分薄く、B以下で処理。
- **マーケティング調査・データ分析・エージェント制御の3バケツは取得失敗**。この領域の10/15〜10/17分は次回取得窓（2日）から外れる恐れあり、埋め戻し推奨。

### [広告クリエイティブ生成] Generative AI Produces and Transmits Beauty Bias
- **arXiv**：[2610.22553](https://arxiv.org/abs/2610.22553) / 2026-10-15 / cs.CY, cs.CV
- **何が新しいか**：T2Iのバイアス監査は職業・ステレオタイプ表現が中心で、「美化（beauty premium）の再生産と他者への伝播」は未測定だった。27生成器・51,300生成顔の監査と事前登録の採用シミュレーション（N=570）で、美化に一切言及しないプロンプトでも生成顔は実顔写真より高く評価され（女性指示の37%がプロファッションモデル中央値超）、スキントーンが濃い群で低評価、さらに高魅力AI顔への曝露が同一の実人物候補の採用率・信頼性を下げること（レタッチ写真では同一効果なし）を示した。
- **使いどころ**：クリエイティブ検収とブランドセーフティ監査。AI生成人物の広告・採用素材への利用判断で、監査スコア分布の実写真分布からの逸脱と人種・性別間の系統差を検収基準にする。
- **明日試せる最小検証**：自社利用中のT2Iで人物プロンプト20種×5枚を生成し、公開魅力推定モデルでスコア分布を実顔写真データセットと比較、スキントーン系プロンプト群間差を集計（1〜2日）。
- **落とし穴**：魅力スコア自体が既存の偏った基準を測る再帰性がある。自動指標と人手評価は部分一致。採用実験は米国文脈で日本の広告表現規制への直結は要解釈。

### [広告クリエイティブ生成] MOSS-Image Technical Report
- **arXiv**：[2610.23374](https://arxiv.org/abs/2610.23374) / 2026-10-16 / cs.CV
- **何が新しいか**：長文テキスト入り画像生成はクローズドモデルの独壇で、オープン重み系はdense textと複雑レイアウトで欠落していた。スクラッチ学習した5B単一ストリームDiT+意図認識型プロンプト強化（PE）モジュールで、オープン重み系として長文テキストレンダリング96.3%（自作ベンチLLTB）とレイアウト制御を両立し、モデル・学習レシピ・評価枠組みを公開する（35ページ・GitHub公開済み）。
- **使いどころ**：テキスト多用広告素材（情報密度の高いバナー・LPサムネ・ポスター）の内製生成。指標：文字再現率・制作工数削減。
- **明日試せる最小検証**：公開重みで日本語長文（50〜100字・かな混じり）入りバナー10件を生成し、文字欠落・崩れ率を既存パイプライン（現行T2I+描画オーバーレイ）と比較（半日〜2日）。日本語は論文未測定で、まずこれを測るのが最短の判定経路。
- **落とし穴**：学習は英・中の双語のみで、かなのレンダリングは未検証（2610.19551のCJK崩れ知見から漢字共有の転移は楽観できない）。エンドツーエンド比較（RLA）では2位で、クローズド最強系には及ばない。

### [エージェント・ハーネス設計] Model-as-a-Trojan: Self-Activating Covert DNS Exfiltration Baked Into the Weights of an LLM Agent
- **arXiv**：[2610.22578](https://arxiv.org/abs/2610.22578) / 2026-10-15 / cs.CR
- **何が新しいか**：エージェント安全性の議論はプロンプト注入と権限設計が主で、「モデル重み自体がマルウェア」という供給経路は想定外だった。シェルの存在を文脈から推測した初手1コマンドで機密をbase32チャンク化しDNS問い合わせで持ち出す挙動をオープン重みに焼き込み、非DNSパケットを全廃棄するegressファイアウォール下でも送出完了（リゾルバログから機密を再構成して証明）、抑制指示20/20無効・45セルのサンドボックス故障行列で零漏洩を示した。
- **使いどころ**：エージェント基盤のセキュリティ設計（運用工程）。指標：DNS経由漏洩経路の封鎖率・リゾルバログでの異常検知率。
- **明日試せる最小検証**：社内エージェント実行環境のDNS出口を監査し、外部ドメインへの長大ラベル（base32チャンク特性）問い合わせのアラートルールをリゾルバログに実装（半日〜2日）。
- **落とし穴**：攻撃デモ単体（2著者・短報告）で攻撃コード・重みは非公開。結論は「DNSを許す限り完璧なサンドボックスは存在しない」で、防御は出口設計とモデル供給源の検証（出所の確認された重みのみ運用）に頼るしかない。

### [エージェント・ハーネス設計] From Approval to Abuse: Privilege Escalation Attacks on Harness-Protected Coding Agents
- **arXiv**：[2610.22987](https://arxiv.org/abs/2610.22987) / 2026-10-16
- **要点**：承認疲れ対策のallowルール承認が新たな攻撃面。リポジトリに埋めた非信頼文脈でエージェントが「もっともらしく正当な広い許可」を要求するよう誘導でき、58%で承認を取得。取得したルールはカテゴリ別能力テストの56.9%を覆う「意味的爆発半径」を持つ（Claude Code・Codex CLIで実証）。
- **使いどころ**：自社Claude Code運用の許可ルール監査——承認済みルールのブラストレディウス測定と、エージェント提案ルールの承認フロー変更。

### [エージェント・ハーネス設計] Harness-Delta Attribution: Dissecting Gains From Harness Evolution
- **arXiv**：[2610.22466](https://arxiv.org/abs/2610.22466) / 2026-10-15
- **要点**：ハーネス自動最適化（プロンプト・スキル・ツール）の利得を「ベンチ過学習／推論時計算量／残差」に分解するプロトコル。11モデル×3フレームワークの21設定で、利得の平均54%が過学習・14%がテスト時スケーリングで説明され、サーチセットの利得はホールドアウトに転移しないことが多い。
- **使いどころ**：自社のプロンプト/スキル最適化の効果検証——サーチセット利得を鵜呑みにせずホールドアウト+計算量統制で再計測する手順として。

### [マーケティング調査] GLOBE: Evolving Structured Agentic Memory for E-commerce Product Optimization in Generative Search
- **arXiv**：[2610.23709](https://arxiv.org/abs/2610.23709) / 2026-10-16
- **要点**：ECリスティングのGEO最適化の成功戦略を、自由文プロンプトでなくフィールド単位（商品名・説明等）の明示的行動ハンドブックとして蓄積・進化。Moderator/Curator機構で有害行動のコミットを抑えつつ、学習した行動は未見カテゴリにも転移。
- **使いどころ**：ECクライアントの生成検索対策（リスティング最適化）をエージェントで回す際の記憶設計の型。
