# arXiv 論文トリアージレポート
**対象期間：2026年8月5日〜2026年8月7日**

## 今週の要点
2本の実務直結型が揃った。1本目は**意味的レイヤ（semantic layer）の自動構築**（Tytan）で、これまで人手で書いていた分析用スキーマ定義をシンボリック解析＋LLM推論で9割方まで自動化し、残りを1問の自然語質問で埋める。BI/レポート自動化のボトルネックが消える線が見えた。2本目は**画面操作の決定論的記憶**（Activity Frames）で、ユーザが言ったことではなく「やったこと」を記録し、定型ルーチンをモデル抜き・ゼロトークンで再現する。エージェント運用コストの見え方自体を変える主張である。A層では動画バーチャル試着（UniVVT）が幾何前処理を全部捨てて意味条件付けに統一、動画クリエイティブの感情制御（EmoWorld）が雰囲気／意味的手がかり／時間推移を分離し、エージェントの足場依存（DCAS）が「単一足場で微調整すると他足場で劣化する」ことを planning の内面化で解いている。

### [セマンティックレイヤーとオントロジー運用] Tytan: Interactive Neurosymbolic Construction of Analytic Semantic Schemas from Relational Data
- **arXiv**：[2608.06331](https://arxiv.org/abs/2608.06331) / 2026-08-06 / cs.DB, cs.AI
- **何が新しいか**：従来、分析用セマンティックレイヤ（エンティティ・メジャー・識別子の役割とテーブル結合）は人手で書き、それが拡張性のボトルネックだった。Tytan は DB のシンボリック解析と LLM の意味推論を組み合わせ、証拠が揃わない決だけを1問の自然語質問でユーザに戻す。8 DB（ブラインド10テーブル本番含む）でカバレッジ100%、自動生成の取得命令1,678件全件が正しく実行され、意味役割一致92-100%。
- **使いどころ**：BI／レポート自動化／NL2BI の前工程。意味的レイヤの作成工数とアナリスト依存度を指標に効く。非技術者を専門家から解放する知識獲得ボトルネックの解除。
- **明日試せる最小検証**（半日）：手元のリレーショナル DB 1つについて、スキーマ内省＋LLM に「エンティティ／メジャー／識別子／結合経路」の役割推論させ、人手定義の意味的レイヤとのカバレッジ差を測る。Tytan 本体の公開コードが無くても、プロトタイプで再現性の下限を確認できる。
- **落とし穴**：外部キー宣言の無い本番10テーブル DB で検証済みだが、社内の場合は列名の命名規約とドメイン辞書の有無が精度を大きく左右する。コード公開が明示されていない点も再現性のリスク。

### [エージェントの長期記憶] Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay
- **arXiv**：[2608.05784](https://arxiv.org/abs/2608.05784) / 2026-08-06 / cs.AI
- **何が新しいか**：従来のエージェント記憶は「ユーザが言ったこと」を保存し、ルーチンは実行のたびにフロンティア推論で再導出していた。Activity Frames は受動取得した画面操作を、モデルを一切通さない決定論的パイプラインで型付きアクティビティフレームにコンパイルし、「ユーザがやったこと」として再現可能にする。1日分のキャプチャを68msで86分の1に圧縮、質問応答98.4%精度（LLLM要約は66-80%）、ミッドTierモデルがフロンティアに並ぶ。ルーチン再現はゼロトークン。
- **使いどころ**：コンピュータ利用エージェント／運用自動化の工程。推論トークンコストを指標に効く。補助的に、Routine Overhead Ratio R=60-343x、委譲可能な反復率7.7-9.0%というエージェントコストモデルの未測定パラメータを初めて実測したコスト計器としても使える。
- **明日試せる最小検証**（2日）：1人の1つの定型タスク（例：媒体レポート作成）の画面操作を1日キャプチャし、公開スキーマ／コンパイラでアクティビティフレームに変換、エージェントに読ませてルーチンをゼロトークンで再現できるか確認する。スキーマ・コンパイラ・評価ハーネスすべて公開済み。
- **落とし穴**：受動的画面キャプチャが前提で、個人情報・業務データの取り扱い（同意・マスキング・保持期間）が法務論点。単一ユーザ・51日のコーパスでの評価であり、組織横断・多職種での一般化は未検証。

## A評価（目を通す）
### [広告クリエイティブ生成] UniVVT: A Unified End-to-End Framework for High-Fidelity Video Virtual Try-on
- **arXiv**：[2608.05745](https://arxiv.org/abs/2608.05745) / 2026-08-06 / cs.CV, cs.AI
- **要点**：動画バーチャル試着を「マスク・姿勢・ワーピングの多段パイプライン」から「意味条件付け動画生成」に再定義し、幾何前処理の誤差伝播を排除。MLLM ベースのシーンタスク知覚器が元動画＋衣装＋指示を潜在トークン化し、軽量セマンティックブリッジで拡散動画生成器へ整列。複数ベンチでSOTA。
- **使いどころ**：ファッション・EC のクリエイティブ制作。撮影なしで着用動画を生成し、制作工数と撮影コストを削減。ただし3段階学習が必要で公開コード未確認、肖像権・実在人物の類似性に法務論点あり。

### [エージェント・ハーネス設計] DCAS: Decoupling CLI Agent Scaffolding to Internalize Planning across Scaffolds
- **arXiv**：[2608.06113](https://arxiv.org/abs/2608.06113) / 2026-08-06 / cs.SE
- **要点**：OpenHands 上で収集した軌跡で微調整したオープンモデルは、別の足場（scaffold）下で大きく劣化し、未学習ベースモデルにはこのズレが無い＝微調整起因の足場ロックインであることを特定。計画構造（明示的計画と暗黙の構造規約）を足場の成果物からモデル能力に内面化するDCAS収集層で、少数の計画意識軌跡が非学習足場でも一貫して効く。
- **使いどころ**：社内でエージェントを微調整・再配備するチーム向け。単一足場への過学習を計画データの設計で防ぐ知見。広告実務への直接接続は薄いが、エージェント全般の移植性設計に効く。

### [広告クリエイティブ生成] EmoWorld: A Decoupled Affective Field for Controllable Emotional Video Generation
- **arXiv**：[2608.06231](https://arxiv.org/abs/2608.06231) / 2026-08-06 / cs.CV
- **要点**：動画生成における感情制御を、大域的雰囲気・意味的手がかり・時間推移の3因子に分離し、凍結Video DiT上で steering。VAS/SAS/TAS各々で感情整列+19%/+37%、時間的変動プロキシ-48%。27感情カテゴリ・複数バックボーンで移植性あり。
- **使いどころ**：動画クリエイティブの感情トーン制御。ブランド世界観に合わせた情緒の微調整に使える。バックボーン（Wan2.2等）と1回の準備段階が必要で、公開コード要確認。
