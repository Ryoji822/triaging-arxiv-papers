## 今週の要点
- 効果検証の土台が固まってきた。識別を支える分布仮定を「母集団のシェア」で段階的に緩めたとき推定がどこまで動くかを計算する統一枠にR/Pythonパッケージが付き（2611.05584）、欠測のあるA/Bやパネル調査の頑健性報告が明日から実施できる形になった。
- 生成系は「高速化の手法競争」と「T2Iが運ぶ価値の偏向測定」に分化。1-4ステップ生成は14BまでスケールするGANベース（2611.06270）、一方で価値中立なプロンプトでもT2IはHofstede 6次元すべて同じ方向に偏ることが960シナリオで確認された（2611.05578）。多市場キャンペーンでは「中立なはず」の素材が特定の価値観を運ぶ。
- エージェントのコンテキスト圧縮は潜在トークン化に移り、ツール出力の70-89%トークン削減と精度改善が両立（2611.06500）。ただし圧縮が拒否挙動を系統的に弱めるという副作用の報告も同時に出ており（2611.06380）、導入時の挙動検査が前提。
- Webエージェントの安全設計では、実行時観測で行動を選ぶReActをやめ「アクセス前にユーザ要求を実行プログラムへコンパイル」する方式が注入ASR 0%かつutility 77.8%でReAct超え（2611.06039）。防御がutilityとトレードオフという前提が崩れつつある。

## S評価（読むべき）
### [データ分析] Sensitivity Analysis in Population Shares
- **arXiv**：[2611.05584](https://arxiv.org/abs/2611.05584) / 2026-11-03 / econ.EM
- **何が新しいか**：従来の感度分析は未測定交絡（Rosenbaum系）など仮定ごとに個別手法が存在し、分布仮定全体を体系的に疑う枠はなかった。本論文は識別に使う分布仮定を「母集団のうちシェアsだけ緩和する」統一パラメータ化で扱い、estimandが取りうる限界値を有限次元計画で計算、しかもシャープな非パラメトリック境界と一致することを保証する。R・Pythonパッケージを公開済み。
- **使いどころ**：効果検証・調査工程。アトリション（中間欠測）のあるA/Bテストやブランドリフト調査で「推定はどれくらいの欠測まで耐えるか」の帯を報告書に載せる。調査結果の頑健性記述と、クライアント説明の信頼性向上。
- **明日試せる最小検証**：過去の欠測ありA/Bログ1件にパッケージを適用し、ATEの感度帯（シェアsを0→1で掃引した限界値カーブ）を1枚の図で出して既存レポートに添付できるか確認。半日〜2日（パッケージ導入のみで理論実装は不要）。
- **落とし穴**：単著・理論中心で実務適用例は3つの示唆（アトリションRCT・構造モデル反実仮想・formula instruments）のみ。「シェア」の意味の解釈にチーム内の共有コストがかかる。ライセンスはCC BY-NC-ND。

## A評価（目を流す）
### [広告クリエイティブ生成] Whose Values Are Generated? Measuring Visual Value Leakage in Multilingual Text-to-Image Generation
- **arXiv**：[2611.05578](https://arxiv.org/abs/2611.05578) / 2026-11-03 / cs.CV
- **要点**：T2Iの文化評価はランドマーク・服装などの表層要素に限定されていたが、Hofstedeの6価値次元を960の社会的シナリオで測定したところ、価値中立なプロンプトでも生成画像はすべての次元で同じ方向（平等>階層、個人主義>集団義務、楽観>禁欲）に偏む。プロンプト言語の影響は小さく、地理的手がかりは一部の次元のみシフト。
- **使いどころ**：グローバルクリエイティブの検品工程。多市場展開アセットの価値偏向チェック（ローカライズ適合性・ブランドセーフティ観点）。ベンチ（VisionValueBench）の公開は要旨に記載なしで、検査軸の社内再現が必要。

### [広告クリエイティブ生成] NextGAN: Towards Simple and Scalable GAN Training for Image and Video Generation
- **arXiv**：[2611.06270](https://arxiv.org/abs/2611.06270) / 2026-11-04 / cs.CV
- **要点**：スカラー批評家の入力勾配を「参照特徴と生成特徴の変位」に回帰させるGAN目的関数。補助損失・オンライン教師スコア・軌道なしで14Bまでの事前学習済み生成器を適応でき、ImageNet 256で1ステップFID 1.36、Wan2.1-1.3BではT2Vの1-2ステップVBench最高（83.13）。コード公開済み。
- **使いどころ**：クリエイティブ制作の生成コスト・レイテンシ削減。バナー量産や動画ドラフトの1-4ステップ生成への差し替え検討。

### [エージェントの長期記憶] Tools Need Not Speak in Text: Latent Context Compression for Agents
- **arXiv**：[2611.06500](https://arxiv.org/abs/2611.06500) / 2026-11-04 / cs.AI
- **要点**：ツール出力をテキストでなく潜在トークンに圧縮して埋め込み空間へ直接注入。Action-Preserving Trainingで圧縮時と全文時の次アクション分布を整合させ、検索エージェント4ベンチ・2モデル家族でトークン70-89%減・実行時間24-56%減かつ精度も改善。コード公開済み。
- **使いどころ**：社内の調査・分析エージェントの長期実行コスト削減。導入には埋め込み空間の工学が必要で、圧縮が拒否挙動を壊す副作用（2611.06380）の検査を併せて。

### [エージェント・ハーネス設計] Securing Web Agents with the Compile-Then-Execute Paradigm
- **arXiv**：[2611.06039](https://arxiv.org/abs/2611.06039) / 2026-11-04 / cs.CR
- **要点**：ReAct型Webエージェントは実行時観測で信頼・非信頼コンテンツを混ぜて行動を選ぶため注入に脆い。Bayaはアクセス前にユーザ要求を実行可能プログラムへコンパイルし、プランニングモデルに生サイトを見せない。信頼できないデータは値や分岐選択にのみ使える。WebArena Verified 581タスクでutility 77.8%（API付きReAct 66.7%超え）、注入ベンチWASPでASR 0%（ReAct系16.2-25.5%）。
- **使いどころ**：社内Web・ブラウジングエージェントの安全設計。防御のためにutilityを諦めるという前提を外せる設計規範。
