# arXiv 論文トリアージレポート
**対象期間：2026年11月1日〜2026年11月3日**

## 今週の要点
- 企業向けエージェント導入の律速が「モデル精度」から**要件発見と本番検証**に移動した。実案件を基底としたFDE評価では、最強モデルでも要件の2割超を取りこぼし、デリバリーは8構成中2つしか全受け入れ基準を通過せず、通過した2件も人間エンジニアの成果に全敗（2611.03551）。
- 売上・広告費系の**重裾アウトカムでA/B検定の前提が崩れる**。少数ユニットが残差変動を握るとWald区間の実質被覆率は名目95%に対し最悪0.42まで低下、非バランス割付では少数側の割合まで落ちる。50/50割付が唯一の防御（2611.03561）。
- エージェント記憶は「構築」から**保守**のフェーズへ（上流事実変更の依存伝播・クエリ時証拠組織化）。防御側は検索露出制御とLean検証ガードレールが実用域に達しつつある。

### [セマンティックレイヤーとオントロジー運用] Can LLM Agents Be Forward-Deployed Engineers? Requirement Discovery and Delivery for Enterprise Text-to-SQL
- **arXiv**：[2611.03551](https://arxiv.org/abs/2611.03551) / 2026-11-02 / cs.CL
- **何が新しいか**：従来のエージェント導入評価はチケット化された要件（既に確定した仕様）から始まっていたが、本論文は**チケット作成前の要件発見フェーズ**を実案件（Oracle方言text-to-SQLの4か月導入・人間FDEの全記録）を基底に評価した初の研究。15モデルでの発見精度と8構成でのデリバリーを人間FDEの納品物と直接比較している。
- **使いどころ**：企業向けデータ分析エージェントの導入（要件定義）工程。要件取りこぼし率（実測40%欠落・誤記）と受け入れ基準通過率（25%）で、導入計画の人間レビュー箇所を特定できる。
- **明日試せる最小検証**：自社の直近エージェント導入案件の受け入れ要件を10〜20項のファクトシートに起こし、あいまいな初回依頼文だけ与えてフロンティアモデル3種に要件発見させ、取りこぼし率を測る。**工数：半日**（3モデル×2〜3回）。
- **落とし穴**：単一案件の事例研究で一般化は未検証。顧客はシミュレータ（事実はファクトシートから再現）、評価ジャッジがGemini系で自己バイアスあり（人間監査一致率70.6%）。主要な失敗モード（本番SQLコンパイル失敗・ベンチ精度と本番の乖離）は案件固有の方言依存の可能性。

### [データ分析] Studentized inference in randomized experiments when a few units dominate the outcome variation
- **arXiv**：[2611.03561](https://arxiv.org/abs/2611.03561) / 2026-11-02 / math.ST
- **何が新しいか**：重裾アウトカム（売上・医療費・顧客支出）で少数ユニットが残差変動の無視できない割合を占めるとき、従来のstudentized統計量＋Wald区間に**明示的な被覆率の下限**（バランス割付で約0.42）を理論的に示し、シミュレーションとRAND/Oregon/顧客支出の3実データで裏付けた。共変量回帰調整（Lin推定量）もこの問題を救わないことを同定。
- **使いどころ**：A/Bテストの分析工程。ROAS・売上・LTVなど重裾指標の検定で、信頼区間の実質被覆率（＝過誤表示リスク）を前提として設計レビューに組み込める。
- **明日試せる最小検証**：過去のA/Bテストログから「上位1%ユニットが残差変動に占める割合」を計算し、dominant unitがいる案件では50/50以外の割付を再現して被覆率の崩れを割付シミュレーションで確認する。**工数：半日〜2日**。
- **落とし穴**：理論は完全無作為化割付が前提（層別・クラスター・スパイクタイム設計への拡張は対象外）。エラーは「保守側」にも「過小側」にも崩れうるため、有意判定の解釈を一律にできない。トリミング/winsorizeはestimand自体を変える別手段。

### [エージェントの長期記憶] A State Change Is Local, Its Consequences Are Not: Dependency-Aware State Revision for Long-Term Agent Memory
- **arXiv**：[2611.02912](https://arxiv.org/abs/2611.02912) / 2026-11-02 / cs.CL
- **要点**：上流の事実が変わっても、記憶システムは矛盾した事実のみ修正し、そこから派生した信念・計画・行動は支持を失ったまま残り続ける。履歴から復元した依存グラフと反実仮想検証（前提を失っても成り立つか）で「支持依存」と「意味的関連」を分離し、依存のみを選択失効するStateGraphを提案。自作ベンチ（50ケース）で深さ3以上の波及についてImpact-F1 +26.0pt、公開ベンチでも劣らず。
- **使いどころ**：長期運用エージェントの記憶保守工程。古い依存関係に基づく誤提案・誤行動の防止。

### [エージェントの長期記憶] Chain on Demand: Deferred Evidence Organization for Long-Term Conversational Memory
- **arXiv**：[2611.02480](https://arxiv.org/abs/2611.02480) / 2026-11-02 / cs.CL
- **要点**：書き込み時の要約・グラフ構築をやめ、ターン単位の原文メモリを保持したまま、クエリ時にアンカー予算配分＋同セッション近傍復元で一時的な証拠チェーンを構築する。LoCoMo全1,986問で76.3%、LongMemEval-Sで86.6%（学習なし・メモリ不改変）。2609.34227の「生ターン選択」と2608.08300の「文脈幅>構造」を統合した形の答え。
- **使いどころ**：対話エージェントの記憶設計。書き込みパイプラインの保守コストをクエリ時処理に置き換える選択肢の評価材料。

### [エージェント・ハーネス設計] Decision Models as Policy Gates for Coding Agents: Explicit Policy Boundaries Improve Detection and Reduce False Alarms
- **arXiv**：[2611.02155](https://arxiv.org/abs/2611.02155) / 2026-11-01 / cs.CL
- **要点**：決定モデル22種＋汎用2種をポリシーエンジンの分類器として、盲検ラベル・封印ホールドアウトで評価。ルールを**例と反例で書く**と23モデルすべてでrecall +5.5〜26.1pt、誤検知も減る（不要割込み30.6%→4.8%、レイテンシ120ms・$0.46/千リクエスト）。データセット・ルール文・ハーネス公開。
- **使いどころ**：コーディングエージェントのランタイムポリシーゲート構築。「ルール文は条文でなく例/反例で書く」という即効性のある処方箋。

### [エージェント・ハーネス設計] LEANGUARD: Lean-Verified Guardrails for Tool-Using Agents

- **要点**：ツール呼び出しをLean4で記述したポリシー（状態述語＋過去時相演算子）で事前チェックし、判定手順自体をLeanで証明・fail-closed化。直接注入成功率57.9%→5.9%、良性タスクは不変。88/252の拒否を証明付き修復（中央値2ms）で復旧。2608.16663のgoverned路線・2610.12292の決定的ルール路線の統合実装。
- **使いどころ**：高リスクツール運用の決定的ガードレール。静的ポリシーの形式的検証が必要な案件の参照実装。

### [エージェント・ハーネス設計] SearchInject: Retrieval Exposure Control for Indirect Prompt Injection in Language-Model Search
- **arXiv**：[2611.02643](https://arxiv.org/abs/2611.02643) / 2026-11-02 / cs.AI
- **要点**：間接注入は攻撃ページが文脈に入る瞬間に制御できる。関連性×虐待手がかり×指示らしさの結合スコアで検疫し、クリーン0.5%偽検疫制約の下でペイロイド露出を83%削減、正規検索のNDCG劣化は0.0018止まり。2608.21230が提唱した「検索時占有率制約」の実装・実測例。
- **使いどころ**：RAG/検索を持つエージェントの入口防御。攻撃成功率の削減は未実証（露出削減まで）である点に注意。

### [エージェント・ハーネス設計] MemHarmBench: Evaluating Cross-Session Prompt Injection in Memory-Persistent AI Agents
- **arXiv**：[2611.01700](https://arxiv.org/abs/2611.01700) / 2026-11-01 / cs.AI
- **要点**：悪性指示が記憶に保持され、攻撃元を消した後の新セッションで、エージェントが**正規タスクを正常に完了しながら**攻撃者の意図に沿った意思決定を行う「行動的にステルスな」侵害を、被害者別（ユーザー／ワークスペース所有者／第三者）に計測するベンチを公開。攻撃成功率型の指標では見えない下游危害を捉える。
- **使いどころ**：記憶を持つエージェントのセキュリティ監査。2608.01637・2610.28810系の攻撃研究への計測道具。

### [広告クリエイティブ生成] Synthetic Realities: Evaluating Human Ability to Distinguish AI-Generated Videos from Real Footage
- **arXiv**：[2611.01990](https://arxiv.org/abs/2611.01990) / 2026-11-01 / cs.CV
- **要点**：無訓練視聴者87人の強制二択で、AI動画の検出精度は平均60%。生成法別ではT2Vが43%（実写判定64%より低い＝本物らしく見える）、I2Vは79%で最容易。検出は技法×テーマの交互作用で決まり、環境映像はAIと誤判定されやすい。
- **使いどころ**：AI生成動画の開示・表現規制対応の前提調査。「T2V素材は人間の目では実写と区別がつかない」ことの引用材料（n=87・36クリップの小規模研究である点を明記して）。
