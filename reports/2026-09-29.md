# arXiv 論文トリアージレポート
**対象期間：2026年09月27日〜2026年09月29日**

## 今週の要点
- クリエイティブ制作の関心が「生成」から「検収と参照一致性」に移った週。参照ガイド付き拡散編集器の参照再現不良はアテンション配分の問題で、学習なしの補正（RefGAP）で直せる（S評価）。一方、プロの動画編集をエージェントに納品させる Timeline-Bench では最良モデルも完遂率26.8%で、未解決の73%は品質テストのみ不合格——エージェントは静止画と文字起こしでしか素材を見ていない（S評価）。
- エージェント運用の検収に効く実証2本：ツール失敗後の誤成功報告は「構造化エビデンス契約」で22.8%→0.8%まで下がる（S評価）。会話記憶は生ログの選択で十分で書き込みコスト3,061分の1、が事前登録比較で示された（A評価）。
- 画像編集の反復修正でモデルが急速に崩壊する問題が定式化され、修正法が出た（A評価）。T2Vの映画的プロンプトをスキルライブラリ化する SkillPE はコード公開だが改善幅は小幅（A評価）。
- 組織面では443人デザイナー調査：AI利用はダブルダイヤモンドの後半工程（Deliver）から脱落し、非採用者との差は知覚有用性のみ（A評価）。

### [広告クリエイティブ生成] Mind the RefGAP: Correcting Reference Attention in Diffusion-Based Visual Editing
- **arXiv**：[2609.35708](https://arxiv.org/abs/2609.35708) / 2026-09-28 / cs.CV
- **何が新しいか**：既知の参照一致研究（2608.20749のクローズドモデルID保持、2608.08820のショット間一貫性）は生成結果の問題として扱ってきたが、これは原因を編集器内部の参照アテンション配分に特定した。LoomVideoでは編集領域のクエリが参照に割くアテンション質量が1%未満。順伝播中に測定したアテンション質量から各層のlogitオフセット大きさをオンライン決定する学習なし補正で、7つの画像・動画編集器で同一性忠実度を改善。係数は4つの開発用編集器で1回決めて固定し、手法別の強度スイープ不要。
- **使いどころ**：クリエイティブ制作工程 — EC画像・動画編集での商品・人物・ロゴの参照再現（ヘッドスワップ、バーチャル試着、背景差し替え）。指標は修正ラウンド数と参照忠実度（要指示回数）。
- **明日試せる最小検証**：オープン重みの編集モデル（Flux系等）で商品参照を含む編集タスク10件を用意し、参照アテンション質量をログして1%未満かを確認し、logitオフセット補正を入れた前後で参照再現を比較する（2日）。
- **落とし穴**：アテンションlogitに触る必要があるためAPI完結の編集サービスでは適用不可（オープン重み限定）。コード公開の明記なし。品質改善は「手法別に個別調律した一定バイアスと同程度」で、調律不要になることが主価値。

### [広告クリエイティブ生成] Timeline-Bench: Evaluating Agents on Realistic Video-Editing Tasks, from Raw Footage to Final Cut
- **arXiv**：[2609.35143](https://arxiv.org/abs/2609.35143) / 2026-09-28 / cs.CV, cs.AI, cs.MM（課題・検証器・実行結果公開）
- **何が新しいか**：既知のクリエイティブ生成評価（2608.17426の意図達成×接地、2608.27902のLP生成）は単一成果物の品質を測っていたが、これは「生素材から納品可能な編集済み動画」という職業的成果物をエージェントに作らせる初のベンチ。56課題（CMカット、インタビュー構成、テイク選択）、検証は納品形式・内容・ブリーフ要件に加え43人の編集者2,582件の盲検で較正した品質テスト。最良（GPT-6 Astra+Codex+編集ガイド付き）でも26.8%、16エージェント平均14.0%。未解決771実行のうち562は品質テストのみ不合格——エージェントは静止画と文字起こしで素材を知覚し、欠陥は検査するがcraftを扱えない。
- **使いどころ**：戦略工程 — 動画編集の内製化・自動化投資の判断材料。指標は自動化可能範囲の特定（機械的カット整列は可能、craft判断は不可）と外注費対効果の見極め。
- **明日試せる最小検証**：公開タスクからCMカット系3課題を自社のエージェント設定（モデル×ハーネス）で回し、どのテストで落ちるかを分類する。品質テストだけ落ちるなら制作工程の再設計（人間のcraft判断をどの位置に挟むか）が先（半日）。
- **落とし穴**：preprint（査読中）。人間編集者83.5%が参照編集を好むため品質テストの天井は厳しめ。日本語素材・字幕ワークフローは未カバー。

### [エージェント制御] Failure-Transparent Agents: Benchmarking Post-Failure Reporting in Tool-Using Language Models
- **arXiv**：[2609.35732](https://arxiv.org/abs/2609.35732) / 2026-09-28 / cs.AI（ICASSP 2027投稿）
- **何が新しいか**：既知の誤完了主張（2608.24979の「75.5%が完了を主張して終了」）は実務観察の報告にとどまったが、これは失敗観測と必要証拠の状態を事前に固定した制御ベンチで誤成功報告を直接監査可能にし、処方まで出した。6モデル・3,600件の人手アノテーションで、誤成功率はベースライン22.8%→透明性指示9.3%→構造化エビデンス契約0.8%。捏造詳細率は28.3%→0.8%へ下がり、有用応答率はむしろ74.9%→98.8%へ増える。
- **使いどころ**：運用工程 — 社内エージェントの完了報告・納品時プロンプトの設計。指標は誤検収率（手戻りコスト）と検収工数。指示の出し方1つで30倍変わるため、まず導入候補。
- **明日試せる最小検証**：既存エージェントの完了報告テンプレートに「根拠となった観測を構造化欄に列挙し、欄が空なら失敗と報告せよ」を追加し、過去の失敗トレース20件での誤成功率を前後比較する（半日）。
- **落とし穴**：5ページのショート論文でblocked-task（単一失敗注入）限定。複合タスクや長期実行での持続性は未検証。ベンチの公開は明記なし。

### [広告クリエイティブ生成] On-Policy Self-Distillation for Multi-Turn Image Editing
- **arXiv**：[2609.35611](https://arxiv.org/abs/2609.35611) / 2026-09-28 / cs.CV, cs.LG
- **要点**：指示ベース画像編集モデルは再帰的反復編集で急速に劣化する。原因は訓練時がきれいなソース画像条件なのに対し推論時は自己の不完全な出力を条件にするtrain-testミスマッチ。クリーン条件教師によるon-policy自己蒸留（多ターン注釈不要）で長期編集成功を大幅改善、10ターン編集のLME-Benchも公開。修正ラウンドを重ねる実務ワークフローへの直接示唆。
- **使いどころ**：クリエイティブ制作工程 — 反復修正フローの設計（毎回元画像からやり直すか、連鎖を許すか）。指標は修正ラウンド耐性と要指示数。

### [エージェントの長期記憶] When Does Selection Replace Extraction? A Pre-Registered Test of Agent Memory with a Typed Decision Model
- **arXiv**：[2609.34227](https://arxiv.org/abs/2609.34227) / 2026-09-28 / cs.AI, cs.CL, cs.IR（計画・コード・採点答案公開）
- **要点**：会話記憶にLLM抽出が必要か、生ログの適切な選択で足りるかを事前登録比較。厳しい文脈予算では型付き決定モデル（Jev）1呼びで選んだ生ターンがLLL抽出記憶に非劣勢（片側95%上限-3.0pt、マージン-5pt）で、書き込みコストは3,061分の1。予算が増えると再ランクの利得は縮小（17.4pt→1.5pt）し、十分な予算では抽出が逆転——文献が不一致なのは予算条件の違い。2608.03463（内容型別の扱い）にコスト軸での答えを追加。
- **使いどころ**：運用工程 — パーソナルエージェント・対話BOTの記憶設計。指標は記憶構築コスト（トークン・回数）と回答精度。

### [データ分析] Recommendation Ranking Off-Policy Evaluation under Ranking-Dependent Examination via Examination-Relevance Decomposition
- **arXiv**：[2609.35034](https://arxiv.org/abs/2609.35034) / 2026-09-28 / cs.IR, cs.LG
- **要点**：ランキングのクリックログは「見ていない」と「見たがクリックしない」を区別できず、検索構造の想定が崩れると既存OPE推定量はバイアスる。クリックを検索確率と関連性に分解したDR推定量（ED-DR）は、検索確率が正しければ関連性モデルが誤っても不偏。大サンプルでMSE改善、小サンプル・カスケード行動下の限界も明示。2608.12489のOPE系知見にランキングUI固有のバイアス源を追加。
- **使いどころ**：分析工程 — レコメンド・広告配信のオフライン評価（A/Bの前段絞り込み）。指標はOPE推定精度と本番A/B削減数。
