# arXiv 論文トリアージレポート
**対象期間：2026年09月14日〜2026年09月16日**

## 今週の要点
- シリコンサンプリングの品質保証が「静的意見の再現」から「情報介入後の信念更新」へ移った。静的評価をパスしたフロンティアモデル5台全てが、審議後の意見変化の人間との対応を破綻させる（逆転・5-7倍過剰・硬直）。メッセージテストへの利用前診断が必須になる（S評価）。
- データ基盤まわりは「構築」から保守と検収の自動化へ。失敗帰属性の編集+ペア評価ゲートでオントロジーを自己進化させる仕組みと、動き続けるデータに対して正解を実行可能コードで与える検収法（ground-truth-as-code）が出た（S評価）。
- 内製エージェントの実務知見が着実に積まれた週。スキル選択はモデル内部信号で足場を汚さず読める、非英語タスクのエージェント間英語強制には最大30ptの税、認可設計の構造レビュー（A評価）。
- フィールド実証2本：ECデリバリ店舗ランキングの本番A/B 3連続、航空座席価格の23週RCTで+11.3%収益（A評価）。
- 一方、常駐マルチエージェント16日間の加圧試験は「検知≠封じ込め」— 脅威を認識しても記憶経由で最長46時間後に注入内容へ行動。安全のフロンティアはモデルでなくシステム（B評価上位）。

## S評価（読むべき）
### [マーケティング調査] Before You Poll with LLMs: A Deliberative Diagnostic Framework
- **arXiv**：[2609.15849](https://arxiv.org/abs/2609.15849) / 2026-09-14 / cs.CL（EMNLP 2026 Main）
- **何が新しいか**：既知のsilicon sampling評価（2608.14079の分散圧縮、2609.07987の統計的置換可能性）はいずれも「静的な意見分布の再現」を測っていたが、これは情報介入後の信念更新（審議後の変化）を人間と比較する動的診断を導入した。America in One Room（526ペルソナ・72問）で5フロンティアモデルを評価すると全滅し、GPT-5.1はバランス情報後に敵対政党への敵意が人間と逆方向に増加（outgroup質問の80%で逆転）、Gemini/Claude/Llamaは方向は正しいが人間の5-7倍過剰、DeepSeekは硬直。機構は自己シコファンシー（与えられた情報でなくモデル内部のペルソナ・ステレオタイプへの同調）。
- **使いどころ**：調査工程 — LLMペルソナによるメッセージテスト・コンセプトテスト（情報露出後の態度変化予測）を掛ける前の診断。指標は態度変化予測の方向・倍率の妥当性で、シリコンサンプリング適用判断の前提になる。
- **明日試せる最小検証**：情報提示前後の回答が残っている過去の調査1本を選び、同じ情報刺激をペルソナに与えて変化の方向と倍率を人間データと比較する（2日）。
- **落とし穴**：人間基準は米政治の審議データ由来。商用カテゴリでの逆転・過剰の倍率転移は未検証。静的再現がそもそもできていないペルソナは本診断以前の問題。コード公開の明記なし。

### [セマンティックレイヤーとオントロジー運用] EvoOntology: A Self-Evolving Ontology Layer for Data Agents
- **arXiv**：[2609.15779](https://arxiv.org/abs/2609.15779) / 2026-09-14 / cs.AI, cs.CL, cs.DB（コード公開）
- **何が新しいか**：既知のセマンティックレイヤ研究は「どう自動構築するか」（2608.06331のDBシンボリック解析+LLM、2609.04697の教師データ自動化）までで、構築後の保守は人のままだった。これはオントロジーをMCPサーバ（スキーマ・内容・ツールの3層）として公開し、エージェント実行の失敗を帰属させた型付き編集を提案、バックボーン条件付きのペア評価を通過した編集だけを採用する自己進化ループを回す。3データエージェントベンチ×4バックボーンで既存の静的セマンティックレイヤ手法に一貫して勝つ。
- **使いどころ**：運用工程 — 社内NL2SQL/データエージェントのセマンティックレイヤ保守工数の圧縮とクエリ精度。指標は保守工数と実行成功率。
- **明日試せる最小検証**：公開リポジトリをBIRD/Spiderサブセットで回し、静的セマンティックレイヤ基線との精度差と編集採択の挙動を確認する（2日）。
- **落とし穴**：ベンチは汎用データエージェント評価で、社内スキーマでの誤編集混入率・長期運用での安定性は別途見る必要。進化の判断基準（ペア評価）自体の保守コストが残る。

### [データ分析] Skill-based Agentic Evaluation for Real-time Data Science Tasks（ground-truth-as-code）
- **arXiv**：[2609.16487](https://arxiv.org/abs/2609.16487) / 2026-09-15 / cs.AI
- **何が新しいか**：分析エージェントの評価は固定の正解JSONやLLMジャッジ頼みだったが（2608.09254は実行後チェックまで）、これは正解自体を「評価時に生データから再計算する実行可能な参照関数」としてコード化し、回答をファクトイド単位・書式不問（文章・表・HTML）で採点する。「先週のオーディエンスサイズは？」のような正解がデータ更新で動く質問の参照が常に現行と整合する。人手一致率（MCC）+29%・評価トークン-16%、正解を与えない自己判定は人手判断と逆相関することを本番スキールの合成再現DBで示した。
- **使いどころ**：レポート工程 — 定期レポート自動化エージェントの検収。指標は検収の判定精度（人手一致率）と評価コスト。
- **明日試せる最小検証**：定期レポートの定常質問5個を参照関数化し、現行エージェントの回答をファクトイド採点にかけて人手チェックとの一致を見る（2日）。
- **落とし穴**：検証は単一スキール・合成DB（本番スキーマ再現）で、コード・データの公開はない。参照関数の整備が初期投資になる。出力が計算で書けない定性レポートには適用外。

### [AIの心理学応用] A light-touch AI literacy intervention helps protect against AI political persuasion
- **arXiv**：[2609.16432](https://arxiv.org/abs/2609.16432) / 2026-09-14 / cs.HC
- **要点**：会話前の短い警告（LLMは説得に使われ情報を選択的に出すことがある）だけで、政治トピックのLLM説得による信念変化が約半減（-48.1%、95%CI [-59.5%, -36.8%]、2実験・計3,208人）。AI全般への信頼は有意に下がらない。2608.11794（説得意図の告知で半減）と合わせ、「何であるか」でなく「何をしようとしているか」の告知が効くのを事前予防接種型でも確認。
- **使いどころ**：調査・戦略工程 — AI利用コミュニケーションの開示設計。消費者向けAI体験・AI生成コンテンツの提示方針のエビデンス。

### [エージェント・ハーネス設計] The Router Within: Eliciting Native Skill Routing from a Frozen LLM（Gavel）
- **arXiv**：[2609.15982](https://arxiv.org/abs/2609.15982) / 2026-09-14 / cs.LG
- **要点**：スキル選択はメタデータ全件を文脈に積む方式（注意力分散・ライブラリ上限）でも外部検索パイプラインでもなく、凍結LLM自身のフォワードパス内に既に信号があり、線形写像2枚で文脈にスキル文を置かずに読み出せる。学習済みで3公開ベンチ+新規372軌跡ベンチにゼロショット転移し、1.2B-16Bの外部パラメータを持つ検索・再ランクを上回る（最大21.9pt）。2608.14036が記録した「プール増加で検索精度29.6→3.3%崩壊」への対抗手段。
- **使いどころ**：運用工程 — スキルライブラリが数十本を超えたときの選択層。指標はスキル選択精度とコンテキストトークン削減。

### [データ分析] Balancing Trial and Reorder: A Hybrid Sequential Transformer-GBDT Ranker（Wolt UVR）
- **arXiv**：[2609.16407](https://arxiv.org/abs/2609.16407) / 2026-09-14 / cs.IR
- **要点**：ECデリバリの店舗ランキングで新規開拓（trial）とリピート（reorder）の緊張を、双方向Transformerエンコーダ+GBDTランカのハイブリッド1本に統合（4モデルを置換）。ラベル平滑化と試行バイアス付きサンプル重みでtrial MRR +12〜30%オフライン、reorderは5カ国中4カ国でregressするが本番CVRは維持。3連続の本番A/BでMerchant Trial Rate +5.5%→+0.45%→+1.31%。
- **使いどころ**：運用工程 — ECクライアントのレコメンド・表示最適化の提案。指標は新規店舗開拓率とCVRの両立設計。

### [データ分析] Learning Choice Model Trees for Feature-Based Multi-Product Pricing（OCMT-MNL）

### [エージェント・ハーネス設計] Authorization Architectures for Tool-Using AI Agents
- **arXiv**：[2609.15906](https://arxiv.org/abs/2609.15906) / 2026-09-14 / cs.CR
- **要点**：ツール利用エージェントの認可の断片的知見（資格情報・アクセス制御・注入・監査）を、プリンシパル階層（ユーザ〜ツール端点の5層）で整理した構造レビュー（約180候補から89一次資料、2023-2026）。7つの構造要件と4層参照アーキテクチャ、3つの配備構成への適用。主要な未解決は実行時強制（認可決定点）と集約の限界。サーベイだが新領域の初の全体マップ。
- **使いどころ**：運用工程 — MCP含む社内エージェントの権限設計・監査チェックリスト。2608.15888/2608.27496などの個別知見の索引として。

### [エージェント制御] Translating the Translator: Decomposing the Cost of English-Forced Inter-Agent Communication
- **arXiv**：[2609.15079](https://arxiv.org/abs/2609.15079) / 2026-09-14 / cs.CL, cs.MA
- **要点**：非英語タスクでエージェント間通信を英語に強制（バック翻訳付き）すると、ネイティブ言語実行比べExact Match精度が13.0pt（スペイン語）〜30.6pt（ヒンディー）低下する「英語ルーティング税」を分離・特定（4言語×n=300、Bonferroni補正後も有意）。英参照との語彙重なりが低いほど悪化＝翻訳漏れが主因。
- **使いどころ**：運用工程 — 日本語パイプラインのマルチエージェント設計。中間表現は日本語のままにする根拠。指標はタスク精度（日本語は未測定のため自社検証が先）。
