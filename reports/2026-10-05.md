# arXiv 論文トリアージレポート
**対象期間：2026年10月1日〜2026年10月5日**

## 今週の要点
- ハーネスの細粒度決定（モデル選択・ツール選択・RAGゲート・注入判定）を1 forward passのSystem-1小モデルに置き換える流れに、初の体系的ペア評価+自己監査が警告を出した。うたい文句の「23.9%コスト削減」は事前スクリーニング費の取りこぼしで実際は4.3%（2610.02267）。安い決定器の採用は決定点ごとに判断が必要。
- text-to-SQLは学術ベンチから本番の失敗（概念が不透明な整数キーで格納され汎用システムは50%cut）に舞台を移した。lookup agent+FK連鎖枝刈り+テンプレート検索のFLINTがEMNLP Industry Trackで本番稼働を報告（2610.03524）。
- エージェント記憶の評価単位が「ユーザーについて何が真か」から「このユーザーとどう協働するか」（関係メモリ）へ拡張。Gold-MemoryとFull-Pipelineのギャップが、frontierモデルでもCaptureの取りこぼしと安全でない削除を起こすことを露呈（2610.03020）。
- T2I検品は否定指示への誤罰が焦点に。固定YES仮定を回答一致規則に置き換える学習なしメトリクスで否定正答19%→88%（2610.03617）。
- 異種モデル間の説得力学はペア固有で、単体の確信度や規模から予測できない。多モデル構成の判断統合は組合わせで評価するしかない（2610.03095）。

### [エージェント・ハーネス設計] Fast Models, Slow Evidence: A Paired and Self-Audited Evaluation of System-1 Decision Models for LLM Agent Harnesses
- **arXiv**：[2610.02267](https://arxiv.org/abs/2610.02267) / 2026-10-01 / cs.AI
- **何が新しいか**：ハーネスの細粒度決定をSystem-1モデル（1 forward pass・クラス確率）に置き換える提案はあったが、その実力を11決定点×7,283例+6,640ロバストネス変種でバイト同一入力のペア比較した初の体系評価。さらに自己監査で「省略された事前スクリーニングコスト（発表値23.9%節約→実際4.3%）」「ゲート精度をend-to-end品質と読み替え（58% vs 98%）」等のheadline主張の歪みを自ら訂正した。
- **検証済みの数字**：ホスト型（Jev）が11決定点中9点で+10.8〜+46.0pp。zero-shotモデルルーティングは両モデルともチャンス以下。RAG関連性ゲートは引き分け。オープン系（Laya）は選択肢の並び替えで30%の回答が変化、候補50件の類似ツール群で31%（Jevは正解一意の項目で98%）。コード・全ケース・生出力・分析コード公開（github.com/David-DL-Space/sys1-eval）。
- **使いどころ**：エージェント運用のコスト最適化。ルーティング/ゲーティングのLLM呼び出しを小モデルへ置き換える採用判断と、ベンダー提案の節約数字の検証手順（運用コスト・レイテンシ指標）。
- **明日試せる最小検証**：公開リポジトリのケースを自社ハーネスのゲート判定に流し、選択肢の並び替え・候補数の変化で判定が何%反転するかを測る（2日）。
- **落とし穴**：評価対象は2モデル限定で製品一般化はできない。zero-shotモデルルーティングへの適用は不可（チャンス以下）。単一著者のプレプリントで査読前。

### [セマンティックレイヤーとオントロジー運用] From Benchmarks to Production: A Text-to-SQL System for Complex Financial Data
- **arXiv**：[2610.03524](https://arxiv.org/abs/2610.03524) / 2026-10-02 / cs.AI, cs.DB（EMNLP Industry Track 2026）
- **何が新しいか**：本番財務DBでは概念が不透明な整数キー（コード表）で格納され、浅いスキーマの人間可読なベンチで強かった汎用text-to-SQLが50%を切る、というベンチ→本番ギャップの原因を特定。自然語概念を参照テーブル制約に動的解決するlookup agent、構造類似クエリテンプレートの埋め込み検索、FK連鎖をトラバーサルするスキーマ枝刈りの3構成（いずれも学習不要）で閉じた。
- **検証済みの数字**：本番財務スキーマ2データセット・359問で同一LLMのSOTAベースライン群を上回り、金融データ取得サービスとして本番稼働中（本文で数値確認済み）。
- **使いどころ**：社内DWH・財務系DBへの自然語クエリ導入。コード表を含む問い合わせの正答率と、アナリストのSQL作成工数。
- **明日試せる最小検証**：自社DBのコード表（店舗区分・商品区分等）を含む質問20件で、素のLLMと「参照テーブル制約を先に解決するlookup agent」を比較し、opaqueキー起因の誤りが何件減るか数える（2日）。
- **落とし穴**：コード・データの公開明記なし（再現は設計記述からの自前実装）。テンプレートバンクは専門家作成でドメインごとの初期投資が必要。評価は自社データ2種限定。

### [エージェントの長期記憶] DyadMem: A Long-Term Memory Benchmark of How Agents Work with Users
- **arXiv**：[2610.03020](https://arxiv.org/abs/2610.03020) / 2026-10-02 / cs.AI
- **何が新しいか**：長期記憶ベンチは「ユーザーの事実・選好」とユーザー横断で再利用する経験しか測ってこなかった。「このユーザーとはどう協働するか」（User-conditioned Relational Agent Memory）という関係メモリを同一路徑で二重注釈し、Capture/Update/Recallを分離採点するフルパイプライン評価を初めて構築した。
- **検証済みの数字**：3,065エピソード・50,961セッション・61,210 QA。20モデル（オープン16+専有4）でGold-Memory QAは一貫して強いがFull-Pipelineで急落。frontierモデルでもCaptureの再現率が低く、不完全なRecallと安全でない削除（unsafe-deletion）が発生。URAM追加は全20モデルに正効果（CC-BY公開）。
- **使いどころ**：パーソナライズアシスタント・カスタマーサクセスbotの記憶設計とベンダー評価。「事実は覚えているが協働履歴を忘れる」失敗の検出。
- **明日試せる最小検証**：自社アシスタントの履歴から関係メモリ（好ましい口調・エスカレーション条件・確認のタイミング）を手動で50件抽出し、現行システムの書き込みログに何件残っているか照合する（2日）。
- **落とし穴**：合成ベンチであり実ユーザーとの分布差は未知。ベンチ成绩がそのまま事業KPIに対応しない（改善の示証はURAM追加の単一実験）。

### [広告クリエイティブ生成] DEPICT: Scoring Text-to-Image Alignment by Answer Agreement
- **arXiv**：[2610.03617](https://arxiv.org/abs/2610.03617) / 2026-10-02 / cs.CV
- **要点**：T2I整合メトリクスは分解質問の固定YES仮定のため、否定指示（non-red cup）で忠実な画像を誤罰してきた。画像のみ回答とキャプションのみ回答の期待一致で採点する学習なし規則に置き換え、重みをキャプションの決定度で付け、全体スコアと統合。否定正答19%→88%、5ベンチ×11バックボーンで学習なし指標を超え、人間相関ベンチ2/3でfine-tuned評価器を上回る。
- **使いどころ**：生成クリエイティブの自動検品。禁止事項・除外指定を含むプロンプトの遵守チェック（検品の自動化と工数削減）。

### [マーケティング調査] CUEing User Simulators: Calibrated User Embeddings for Multi-Turn Benchmarking
- **arXiv**：[2610.02460](https://arxiv.org/abs/2610.02460) / 2026-10-01 / cs.CL
- **要点**：ユーザーシミュレータの忠実度はスタイル再現で測られてきたが、実ユーザーの成功率・失敗パターンとの一致（outcome calibration）が欠けていた。実セッションを符号化→連続表現をサンプリング→ペルソナコマンドに復号するCUEで学習なしに達成。τ²-Benchでシミュレータ起因の誤りが減り、実ユーザーの失敗モード・成功率・タスク×ユーザー別結果を他手法より忠実に再現。カスタサブ中心でfitしても文書作成・チューター・雑談に汎化し、simulator LLMを変えても有効。
- **使いどころ**：シミュレータによるエージェント評価・silicon samplingの事前品質検査。実A/Bの前に「このシミュレータは失敗の起き方まで再現しているか」を確かめる手順として。

### [広告クリエイティブ生成] Generative Cinematographer: Composing Camera and Object Motion in 3D
- **arXiv**：[2610.02180](https://arxiv.org/abs/2610.02180) / 2026-10-01 / cs.CV
- **要点**：動画の運動制御は2D軌道やドラッグ指示で、カメラと被写体が同時に動くと曖昧だった。単一画像を編集可能な3Dシーン足場に持ち上げ、カメラパスと前景の局所3Dハンドル（部位ごとに独立）を世界座標系で指定してguidance mapに射影、Wanの軽量guidance branch+LoRAで追従させる。カメラ移動下の幾何一貫性と制御性が改善。
- **使いどころ**：動画広告のカメラワーク指定（プラン・寄り・追いなど）の初稿制御。撮影指示の再現度とtake成功率。

### [AIの心理学応用] Peer Influence across Heterogeneous AI Models
- **arXiv**：[2610.03095](https://arxiv.org/abs/2610.03095) / 2026-10-02 / cs.AI
- **要点**：異種オープンモデル7種×3タスクで、意見が割れた2体間の説得（1回の交換後の判断シフト）を測定。シフトの大きさは話者の説得力より聴者の感受性で決まり、単体の確信度・規模からは予測できない。小モデルが大モデルの判断を覆せる組み合わせがあり、異質性は説得を増幅も抑制もする。
- **使いどころ**：多モデルパイプライン・レビューbot等の判断統合設計のリスク評価。後段モデルが前段の判断を覆す構成は組合わせ実験でしか評価できない。
