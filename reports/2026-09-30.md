# arXiv 論文トリアージレポート
**対象期間：2026年9月28日〜2026年9月30日**

## 今週の要点
- 生成動画の「文字」が品質管理の主戦場になった。VidScribe は動画内テキストを4生成形式×12軸で系統測定し、内容認識とグリフ正確さは別物で、文言差し替え（V2V）が最大ボトルネックと示した。動画CMの差し替え・ローカライズ運用に直結する。
- エージェント記憶の論点が「何を覚えるか」から「事実の鮮度・時間的形状」に移動。LAPSE は記憶書き込みが進行形ファクトを現在形に扁平化し、期限切れの事実で行動する事故を誘発すると測定した。
- ツール出力への「もっともらしい誤り」流入という新リスクが定量化された（ToxicBench）。分析エージェントは毒入り出力を確認したうえで採用する盲従を示す。
- プロンプト注入防御は検出型から常時介入型（steering、トークナイズ制御）へ移行中だが、白盒サービング前提のものが多く API 運用には適用限界がある。

### [広告クリエイティブ生成] Beyond Legibility: Benchmarking Visual Text Rendering and In-Place Editing in Unified Video Generation
- **arXiv**：[2609.36598](https://arxiv.org/abs/2609.36598) / 2026-09-29 / cs.CV
- **何が新しいか**：従来の動画評価は文字を副次的とみなし静的OCR指標で済ませていたが、T2V/R2V/I2V/V2Vの4形式×12軸の直交要因空間で文字能力を分解し、「内容認識とグリフ正確さは分離する」「劣化は悪撮像条件ではなく文字固有の構造・時間要因に集中する」「V2V部分編集が非対象テキストまで壊す主ボトルネック」を初めて実証（803人手検証サンプル・11システム）。ベンチ整合の選好最適化で生成も改善する訓練信号を同梱。
- **使いどころ**：動画クリエイティブの検品・文言差し替え工程。リテイク率と検品工数の削減（文言入り動画の発注前チェックリスト化）。
- **明日試せる最小検証**：自社の動画生成ワークフローで商品名・キャッチコピー入り10本を生成し、V2Vで文言差し替えを3パターン試して失敗要因（グリフ崩れ／時間不安定／非対象テキスト破壊）を分類集計する。**工数：1日**。
- **落とし穴**：データセットはCC BY-NC-SA（非商用ライセンス）で業務パイプへの再利用はライセンス確認が必要。ICLR 2027 審査中。評価は自動メトリクスと人手確認のハイブリッドで完全自動化ではない。

### [エージェントの長期記憶] Memory Consolidation Flattens the Temporal Shape of User Facts
- **arXiv**：[2609.36457](https://arxiv.org/abs/2609.36457) / 2026-09-29 / cs.CL
- **何が新しいか**：既知の記憶事故研究（権限崩壊・ポイズニング・エビクション）は「内容の誤り」を扱ってきたが、本論文は「事実の時間的形状（進行中か恒常か）」が書き込み時に消失する側面扁平化（aspectual flattening）を対照文ペアで初めて測定した。3ライター×11構成すべて、および実運用パイプライン mem0・Graphiti・Letta で一方向の扁平化（381対中244）が再現し、リーダーは扁平ノートで確認せず行動しやすくなる。
- **使いどころ**：パーソナライズド／カスタマーエージェント運用。期限切れ事実に基づく誤アクション率・不要な確認オーバーヘッドの低減。
- **明日試せる最小検証**：社内メモリ（mem0/Letta等）の保存ノートから「会話時点で進行形だったファクト」100件を抽出し、動詞の時間形式が保存されているかを監査する。**工数：半日**。
- **落とし穴**：ベンチLAPSEの公開をabsページで確認できず再現は自作対照ペアになる。リーダー行動への影響はexploratoryで効果量は小さい。書き込み時にアスペクト保持させるコストは未測定。

### [エージェント制御] When Tools Silently Lie: Evaluating and Mitigating Blind Compliance in Tool-Augmented Data Agents
- **arXiv**：[2609.37153](https://arxiv.org/abs/2609.37153) / 2026-09-29 / cs.AI, cs.CR
- **何が新しいか**：従来の毒入れ研究はコーパス／検索結果の事前汚染が対象だったが、実行時にツールが返す「もっともらしい誤り」（数値・ラベル・スキーマ・検索の4種）に対するデータエージェントの盲従を、同一ソースのclean/poisonedペアで分離測定した。毒入れでタスク成功率26-39pt低下、リトライは単発毒にのみ有効で、反復毒では「確認したうえでの誤答採用」が残ることを人手アノテーション（200軌跡・一致率96%）で確認。
- **使いどころ**：分析エージェントの検収・監査設計。誤分析率の抑制（証拠可用性と回答選択の2軸で監査を実装）。
- **明日試せる最小検証**：社内分析エージェントの数値ツール（ダッシュボードAPI等）の出力に1箇所だけ誤値を注入し、エージェントが検知・リトライ・最終採用のどれに至るかを10タスクで記録する。**工数：1日**。
- **落とし穴**：GPT評価・3アダプタ限定。緩和策は分析枠組みの提示止まりで決定的な防御ではない。ベンチは公開（GitHub、CC BY 4.0）。

### [広告クリエイティブ生成] Decompose Radicals, Then Reward: Fine-Grained Inspection for Accurate Chinese Text Rendering
- **arXiv**：[2609.37569](https://arxiv.org/abs/2609.37569) / 2026-09-29
- **要点**：漢字描画のRL報酬をOCRの文字単位でなくIDS（部首＋空間関係演算子）分解のトークン単位に細粒度化（IDSpect）。Qwen-Image の GRPO 後訓練で LongText/GenTextEval で先行、推論コスト増なし。既知の漢字ポスター報酬設計（2608.19637）への新しい答え。
- **使いどころ**：CJK圏クリエイティブの漢字リテイク率削減。日本語への転用はIDS構造の近さから有望だが要自社検証。

### [エージェント・ハーネス設計] Render Before Reading: Visual Rendering as a Prompt Injection Defense
- **arXiv**：[2609.36121](https://arxiv.org/abs/2609.36121) / 2026-09-28
- **要点**：マルチモーダルLLMはテキスト経由の敵対指示に画像経由より従う（text-centric instruction tuning 起因のモダリティギャップ）。信頼できないペイロードをタイポグラフィ画像に描画してから渡すだけで学習なしでASRが下がる（10モデル・2ベンチ、適応攻撃と人間レッドチームに対しても有効）。2609.04533（画像埋め込み攻撃の成立）の逆方向の防御利用。
- **使いどころ**：RAGエージェントの取得ドキュメント前処理。実装は軽量だがOCR的処理コストとユーティリティ低下の測定が前提。

### [データ分析] OTROPE: Optimal Transport-based Robust Off-policy Evaluation for Large Language Models
- **arXiv**：[2609.36264](https://arxiv.org/abs/2609.36264) / 2026-09-28
- **要点**：新モデルの評価を、少数の旧モデル人手ラベルからのOPEに定式化。ブラックボックスでも尤度不要で、最適輸送による分布補正＋代理予測子の二重頑健評価。弱い評価者LLMのアンサンブルが強評価者に迫る。コード公開。
- **使いどころ**：LLM差し替え時の評価コスト削減（運用工程、評価用ラベル数・評価コスト）。

### [広告クリエイティブ生成] PreviewDiff: Multimodal Critic-Guided Search over Diffusion Latents
- **arXiv**：[2609.36199](https://arxiv.org/abs/2609.36199) / 2026-09-28
- **要点**：テスト時探索を最終サンプル選択（Best-of-N）でなく、デノイズ中間段階で部分プレビューをVLM批評家が採点・自然言語フィードバックで分岐する探索に変える。予算同額のBest-of-Nとスカラー探索を一貫して上回る（訓練なし）。画像・動画両方。
- **使いどころ**：構成的要件が厳しい商材画像生成（個数・属性バインディング・空間関係）の初稿精度向上、再生成コスト削減。

### [AIの心理学応用] Illusory Truth or Mere Exposure? Model-Dependent Repetition Effects in LLM-Based Social Media Simulations
- **arXiv**：[2609.36278](https://arxiv.org/abs/2609.36278) / 2026-09-28
- **要点**：LLMソーシャルシミュレータの錯誤真実効果（ITE）の再現はモデル固有で、Gemma-3=真正ITE、Qwen2.5=単純暴露効果、GPT-5-nano=反復効果なし、と質的に4パターンに分かれる（33.6万評定・4モデル）。シミュレータ選定自体が合成対象者のバイアス構造を変える。
- **使いどころ**：シリコンサンプリングによる事前テスト設計でのシミュレータ選定基準（調査工程、バイアス再現性）。温度では変わらない点にも注意。

### [エージェントの長期記憶] UpliftMem: Learning Set-Level Uplift for Agent Memory Retrieval
- **arXiv**：[2609.36805](https://arxiv.org/abs/2609.36805) / 2026-09-29
- **要点**：記憶検索を意味類似でなく「同じ実行者のメモリなし実行とのセットレベルuplift」から学習。ロールアウト予算をEVSI基準のプローブ選択で配分し、訓練後はテスト時プローブ不要。ALFWorld/WebShop/BigCodeBench で最高成功率。既知のクエリ時証拠森選択（2608.26983）に対し実行フィードバックからの学習という別答え。
- **使いどころ**：エージェント運用での記憶利用率と成功率あたりコスト改善。

### [エージェント・ハーネス設計] GitHarness: Git Init Your Harness Working Memory for Perpetual User Requirements
- **arXiv**：[2609.36789](https://arxiv.org/abs/2609.36789) / 2026-09-29
- **要点**：長期協働での要件変更を、要件状態と作業状態のペアをGit型の分岐可能なバージョン履歴で管理し、ブラックボックスRL訓練のGitエージェントが互換な過去状態を選択・復元して局所更新させる。 Obsolete情報の持ち込みと全域書き直しの両方を防ぐ。ベンチMTAgentBench構築。
- **使いどころ**：ブリーフ変更の多い社内エージェント開発の再作業率削減（対象ハーネス・下流モデルは固定で後付け可能）。

### [セマンティックレイヤーとオントロジー運用] Lost in Conversation or Lost in Translation? Diagnosing Multi-Turn Degradation in RAG
- **arXiv**：[2609.36700](https://arxiv.org/abs/2609.36700) / 2026-09-29
- **要点**：多ターン会話化でRAGは最大21%相対低下・信頼性47%低下し、失敗は「会話的言い換えによる検索クエリ歪み（translation）」と「検索は成功するがターン分散証拠の統合失敗（conversation）」の2型に分解（10LLM×8検索系×150万会話シミュレーション）。
- **使いどころ**：社内チャットボット・調査ボットの多ターン評価設計（単ターン指標だけでの合格判定を避ける）。

### [広告クリエイティブ生成] Evaluating the Evaluators: Diagnosing Large Multimodal Models for AI-Generated Image Assessment
- **arXiv**：[2609.37576](https://arxiv.org/abs/2609.37576) / 2026-09-29
- **要点**：LMM評価者を意味・品質・真正性・責任の4面38下位軸で診断するSQUARE-Bench（生成約1万＋実写3千、22生成器、23 LMM）。トップ専用モデルは人間専門家単体を超えるが下位軸でばらつき、次元別診断フィードバックによる反復編集で選択的改善と画質トレードオフ。
- **使いどころ**：AIGC検品のVLMジャッジ選定とその弱所マップ（検品工程、判定一致率）。
