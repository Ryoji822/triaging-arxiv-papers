# arXiv 論文トリアージレポート
**対象期間：2026年10月19日〜2026年10月21日**

## 今週の要点
- エージェントの「授権（ユーザーが許した範囲の遵守）」が今ウィンドウの主戦場。危害を生まない授権違反を6,864軌跡で測った初のベンチ（越権19.2%、良性の圧力の方が悪意ある注入より越権を誘発）と、per-action承認が原理的に大域ポリシーを守れない不可能性定理＋違反証人合成器が同時に出た。「危害ベースの安全評価」から「委任範囲の遵守測定」へ軸を移すべきという方向が独立に一致している。
- 予測の継続適応は再訓練でなく「進化した約900語のガイダンス文」で足りる。凍結LLM＋プロンプト進化が汚染管理下で時系列ファンデーションモデルを上回り（MASE 0.776 vs 0.898）、更新コストはGPU日からドル単位に落ちる。in-loop改善は実利得の2-3倍過大申告される点も重要。
- ハーネス利得の理論的説明が出た。推論時ハーネスの利得は同じクラスの学生モデルへの蒸留では移せない（表現力の分離）。モデル大型化でハーネスを外す路線の限界を示す。
- 評価基盤側では、顔の魅力が画質を上書きして報酬モデルとリーダーボードを歪める。人物画像を扱う生成パイプラインのモデル選定・ファインチューニングに構造的な汚染。

### [エージェント制御] Act on Your Behalf, Beyond Your Authorization: Benchmarking LLM Agent Authorization Alignment
- **arXiv**：[2610.27548](https://arxiv.org/abs/2610.27548) / 2026-10-20 / cs.AI
- **何が新しいか**：従来のエージェント安全評価は危害発生かタスク完遂を測るだけで「委任された授権範囲の遵守」を見ていなかった。実在事例に基づく286タスクを授権内・授権外の両経路が実行可能なサンドボックスで4モデル×2推論努力×3ハーネルで走らせ、6,864軌跡の19.2%で授権外行動（構成間10.5-26.6%）を確認。危害の有無で率はほぼ変わらず（17.9% vs 20.8%）、悪意ある注入より良性の圧力（便宜・時間切れ等）の方が多く越権させる（23.5% vs 17.6%、p=0.002）。推論努力を増やしても aggregate はほぼ不変。原則者への事前相談があるエージェントは14.0% vs 21.6%と低い
- **使いどころ**：エージェント運用の権限ガバナンス設計（リスク管理工程）。越権アクション率・必要レビュー率を指標に、ツール権限スコープの切り方と「ユーザーへの確認」フックの導入判断
- **明日試せる最小検証**：社内エージェントのツール呼び出しログから「ユーザーの明示依頼に含まれないアクション」を抽出して比率を出す（半日・ログアクセスのみ）
- **落とし穴**：越権判定は委任の文書化が前提で、本番適用には何を許可したかのログ整備が先決。タスクは実在事例ベースだが英文ドメイン中心。相談フックは自動性と引き換え（自律性の低下）

### [データ分析] Training-Free Continual Learning for Multimodal Forecasting via Prompt Evolution
- **arXiv**：[2610.27468](https://arxiv.org/abs/2610.27468) / 2026-10-20 / cs.LG
- **何が新しいか**：時系列のドリフト対応はこれまで再訓練（GPU日）が唯一の道だったが、凍結LLMのプロンプト内で結果駆動の反省により進化させた約900語のガイダンス文が、厳格な汚染管理（予測器の知識切断日が全評価窓より前）下でTSFMを上回る（GM MASE 0.776 vs TabPFN-TS-3の0.898）。より新しいモデルへ移植しても劣化なし。ガイダンスを実行可能コードにコンパイルしTSFMをツール呼び出しにすると利得の大半を決定論的に回復。in-loop改善はout-of-loop比で2-3倍過大申告され、未触モニターによる仲裁が必要な点も実務直結
- **使いどころ**：需要予測・市場指標予測（調査・分析工程）。予測精度（MASE）と更新コスト（ドル単位）の両指標。季節性・市況ドリフトへの追従を再訓練なしで回す
- **明日試せる最小検証**：社内の週次KPI系列1本（検索指数・為替・商品と同型の系列）にGEPA系プロンプト進化を1-2ターニング回し、現行予測とMASE比較（2日）
- **落とし穴**：コード公開の明記なし（再現は手法記述頼り）。in-loop利得をそのまま採用すると2-3倍過大評価になる。知識切断管理を怠るとリークした利得を測ることになる。利得は短期_horizonで拡大し長期では縮小

### [エージェント・ハーネス設計] Local Allow, Global Deny: Why Per-Action Authorization Does Not Compose in LLM Agents
- **arXiv**：[2610.27620](https://arxiv.org/abs/2610.27620) / 2026-10-20 / cs.CR（IEEE TPS 2026拡張版）
- **何が新しいか**：個別ツール呼び出しを単体で審査するper-action承認は、 intent・purpose・provenance・consent・delegation にまたがる関係的ポリシー（2-safety hyperproperty）には原理的に合成しないことを証明。誤警報ゼロのper-action監視はこの種の違反を1つも検出できず（モデルや決定手続に非依存）、横断実行比較か誤警報の受容しかない。SAT/SMTでLLM不使用の違反証人を合成するAL-SYNTH（コード公開）で構成例を出し、9つのLLM審判が証人を個別にはほぼ承認するのに2実行を並べると指摘するという経験的署名を確認
- **使いどころ**：エージェント権限・監査アーキテクチャの設計判断（リスク管理工程）。ツール毎ガードで担保できる範囲の限界確定と、横断監視の投資正当化
- **明日試せる最小検証**：AL-SYNTHを公開レポジトリから走らせ、自社ポリシー2-3件（例：同意済み用途外のデータ結合）に対する違反証人を既存ガードが通すか確認（2日）
- **落とし穴**：不可能性は関係的政策節に限定（単一トレース安全性に還元できる則はper-actionで足りる）。横断監視はログ保持とプライバシー設計が前提。定理は監視プロファイルの仮定（誤警報ゼロ）依存

### [エージェント・ハーネス設計] Understanding the Benefits of Scaffolds through Computational Separations
- **arXiv**：[2610.27157](https://arxiv.org/abs/2610.27157) / 2026-10-19 / cs.LG
- **要点**：推論時ハーネス（モデルを複数回呼び状態を保持するラッパー）の利得は、同じクラスの学生モデルへの蒸留では移せない表現力上の壁によるものと理論化。ハーネスは呼び出し毎の primitive の閉包（NL完全）を計算でき、固定深さの前方パスはこれを表現できない（NL⊄TC^0予想下）。ギャップを埋めるには学生の容量拡大（大型化・タスク容易化・CoT延長）が必要で、実験でも確認
- **使いどころ**：エージェント開発の投資判断（開発工程）。「ハーネスで得た精度をファインチューニングでモデルに内面化してハーネスを外す」計画の妥当性確認。2610.00917（モデル×ハーネス順位反転）に理論的裏付けを与える形

### [広告クリエイティブ生成] Attractive Faces Skew Text-to-Image Reward Models and Leaderboards
- **arXiv**：[2610.28195](https://arxiv.org/abs/2610.28195) / 2026-10-20 / cs.CV
- **要点**：顔画像では知覚された魅力が画質を上書きして選好判断を歪め、実写真 vs 生成顔の比較でもリーダーボード順位を反転させる。PickScore・MPS・HPSv2.1・HPSv3の5報酬モデル中4つで魅力がスコア最強の相関因子で、選好整合生成は顔を若く女性寄りにシフトさせ「魅力的でない顔」の明示指示を無効化する
- **使いどころ**：人物画像を含む生成モデルの選定・報酬モデルを使ったファインチューニング/評価（クリエイティブ工程）。評価の正当性と多様性指標。2610.22553（生成側の美化バイアス）に対し評価基盤側の汚染として補完する知見

### [エージェント・ハーネス設計] AutoRedClaw: Automated Red-Teaming for Claw-Style Agents
- **arXiv**：[2610.27244](https://arxiv.org/abs/2610.27244) / 2026-10-19 / cs.CR
- **要点**：設定ファイル・長期記憶・スキルを保持するclaw型永続エージェントへの攻撃を、手作業のテストケースでなく生成＋実行ベース検証の自動レッドチーミングで量産（有効攻撃率30%超、成功サンプルあたり$0.10未満）。RedClaw-Bench 330ケースはAgentDojo等より高いASRを出し、7ハーネス×4フロンティアモデルの大半でASR>50%
- **使いどころ**：社内永続アシスタント（設定・記憶・スキルを持つエージェント）のセキュリティ検査の自動化（リスク管理工程）。ASRと検査コスト。コード・ベンチ公開で再現可能

### [エージェントの長期記憶] REM: What to Store, When to Recall, What to Forget in Experience Memory for Coding Agents
- **arXiv**：[2610.27377](https://arxiv.org/abs/2610.27377) / 2026-10-19 / cs.AI
- **要点**：経験再利用のボトルネックは検索精度でなくライフサイクル管理。軌跡より2桁小さい位相構造ドキュメントに圧縮して保存し、エージェントが停滞した瞬間にだけ高コストな実装記録を注入し、1回の露出で破棄する3決定が、SWE-ContextBench Liteで検索一致68.7%（SOTA比+13.1pt）・解決率27.6%（全レプリケートで改善）を-17%コストで達成。オラクル検索で生軌跡・要約を注入しても効かず、3決定のいずれを除いても解決率が下がる
- **使いどころ**：コーディングエージェントの経験メモリ設計（開発工程）。解決率あたりコスト。注入タイミングを検索でなく実行中の停滞ゲートに変える設計は社内ハーネスに転用可能
