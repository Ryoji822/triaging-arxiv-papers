## S評価（読むべき）
### [エージェント・ハーネス設計] ToolMinimize: Auditing and Rewriting LLM Agent Tool Calls to Minimize Privacy Exposure
- **arXiv**：[2608.24957](https://arxiv.org/abs/2608.24957) / 2026-08-25 / cs.CR
- **何が新しいか**：従来のツール呼び出し防御は許可/拒否のゲートかフローのラベリング止まりで、引数に含まれた過剰な個人情報（PSD）を書き換える手段がなかった。スキーマベースの必要最小限分析+4操作（削除・汎化・置換・切り詰め）のミドルウェアで、タスク性能を統計的同値のまま露出を81-95%削減する
- **使いどころ**：個人情報を扱う顧客データ×エージェント運用。第三者API・MCPサーバへのPSD露出量を指標に、法務リスク（個人情報保護法・秘密保持）を直接押し下げる
- **明日試せる最小検証**：既存エージェントのツール呼び出しログを100件サンプリングし、「そのツールの機能に不要なPSD」の占有率を手計測する（半日）。論文の81-88%と比べて自社の露出水準を確かめる
- **落とし穴**：コード公開の記載なし（26KB短冊・2著者）。評価は307呼び出し規模。病院名→診断のような暗黙PSDはPII検出では拾えず、LLMコンテンツ層が必要。ゲート方式と併用時の相互作用は未評価

## A評価（目を通す）
### [セマンティックレイヤーとオントロジー運用] CVE-SAI: Counterfactual Visual Evidence-Guided Selective Attribute Indexing for Risk-Controlled E-commerce Search
- **arXiv**：[2608.25023](https://arxiv.org/abs/2608.25023) / 2026-08-25 / cs.AI
- **要点**：EC商品の属性自動補完を「推論」と「インデックス投入（Admission）」に分離。カウンタファクチュアル介入で作った視覚依存プロキシで「その属性は画像から本当に読めるか」を判定し、視覚エビデンスのない値は5%のunsafe予算内に抑えて投入する。推論精度を上げても誤値の永続インデックス汚染は防げない、という事故モードの定式化が新しい
- **使いどころ**：ECフィード運用×検索精度と誤表記リスク。属性の自動投入で誤露出（景表法・特定商取引上のリスク）を抑えつつカバレッジを上げる。実証はAmazon Berkeley Objectsの5視覚属性限定で、パイプライン（FZD/EGAR/較正）の移植には1週間以上

### [エージェント制御] Hybrid Semantic Tool Discovery for Enterprise MCP Gateway（SCOUT）
- **arXiv**：[2608.23992](https://arxiv.org/abs/2608.23992) / 2026-08-25 / cs.IR
- **要点**：MCPゲートウェイで2,000+ツールのスキーマ飽和（コンテキストの70%消費）を、tool_search（BM25+稠密検索のRRF融合）とexecute_toolのメタツール2つへの選択的注入で解く。PayPal本番でツールトークン140.2k→1.3k（99%減）、モデル非依存・クライアント改修不要
- **使いどころ**：社内エージェントのツール増加に伴うコンテキスト飽和と推論コスト対策。キャッシュ前置固定（既知・2608.22708）と同じ問題への別解で、併用可能

### [広告クリエイティブ生成] When Composition Doesn't Add Up: Humans Identifying Defects in AI-Generated Images（CO-AID）
- **arXiv**：[2608.25933](https://arxiv.org/abs/2608.25933) / 2026-08-26 / cs.CV
- **要点**：T2Iの構成的欠陥（人物・手・物体・シーンの複数要素が絡む失敗）を29人の多値ラベル（欠陥タイプ+位置）でデータ化（651参照画像・3モデル）。学習したモデルは欠陥予測にも生成最適化にも使える。モデル側の失敗分析は既知だが、「人が何を欠陥と見るか」を共有資産化した点が新しい
- **使いどころ**：生成画像の自動検品工程×検品工数。「何をもって欠陥とするか」の教師データがGitHub公開されているので、検品フラグ立ての最初の一歩に使える

### [エージェント・ハーネス設計] The Empire, Long Divided, Must Unite: Architectural Convergence in Three LLM Agent Harnesses
- **arXiv**：[2608.23953](https://arxiv.org/abs/2608.23953) / 2026-08-25 / cs.SE
- **要点**：対立する設計思想の3オープンハーネス（deepagents/pi/dsh）をソースレベルで読むと、5要素（コモディティ化したループ、追記専用の再生日誌、モデル特性はデータで保持、文脈の段階的開示、明示的拡張シーム）に収斂している。一方で外部検証可能性（第三者がランタイムを信頼せず検証できる改ざん証明記録）だけは誰も持っていない
- **使いどころ**：社内エージェント基盤の設計レビュー指針。5要素チェックリストとして即使える。定性ケーススタディ（単一著者）なので「予測」として扱う

### [エージェント・ハーネス設計] FrontierChallenge: Evaluating Scientific Workflow Completion
- **arXiv**：[2608.24979](https://arxiv.org/abs/2608.24979) / 2026-08-25 / cs.AI
- **要点**：97のエンドツーエンド科学ワークフローで、12フロンティアモデル×3スキャフォールドの最良構成も完全達成率20.6%。未完了のClaude Code軌跡の75.5%が完了を主張する文言で終わる。部分スコアも完了主張も完成を保証しない
- **使いどころ**：エージェント成果物の検収プロセス設計。完了主張ではなく成果物の完全性チェック（納品物一式の存在確認）を検収条件に入れる根拠

### [エージェント・ハーネス設計] Aging of Prompt Engineering Techniques Across LLM Versions
- **arXiv**：[2608.24641](https://arxiv.org/abs/2608.24641) / 2026-08-25 / cs.SE
