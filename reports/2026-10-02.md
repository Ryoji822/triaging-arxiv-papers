# arXiv 論文トリアージレポート
**対象期間：2026年9月30日〜2026年10月2日**

## 今週の要点
- 生成系の「検品」が主戦場。シーン内テキスト（VTR-Bench/ViTeX-Bench）、隠れた物理特性の盲点（PhysicsLENS）、多様性崩壊の次元診断（DiVid）に加え、評価器自身のバイアス監査（2610.01670）まで出揃い、生成品質の測り方が軸単位に細分化しつつある。
- 「モデル単体の順位は当てにならない」が66構成の統制データで定量化された（2610.00917）。エージェント選定はモデル×ハーネス×タスクの組で評価するしかない。
- 制作パイプラインに即効な学習なし手法が2本：統合編集モデルのT2Iモードへの区間切替え（2610.01681）と、音声付き動画生成のstem分離（2610.00691）。
- 因果分析では、embedding共変量を使うDMLの妥当性条件と感度分析が整備された（2610.01935）。クリエイティブ埋め込みを分析に使うケースの必読論文。

## S評価（読むべき）

### [データ分析] Pragmatic DML with AI-Learned Representations
- **arXiv**：[2610.01935](https://arxiv.org/abs/2610.01935) / 2026-10-01 / econ.EM, stat.ML
- **何が新しいか**：テキスト・画像をembedding化して共変量に使う因果推定は普及しているが妥当性条件は未整備だった。歪みが「アウトカム回帰の表現誤差×バランス重み（Riesz表現）の表現誤差の積」で決まることを示し、（1）cross-fit DMLでWald推論が有効、（2）fold毎の表現学習・fine-tuningがDML推論と両立、（3）誤差が大きい場合は解釈可能な感度領域とエンドポイントのroot-n推論を返す、の3つを実用枠組み化。
- **使いどころ**：マーケティング調査・データ分析工程。クリエイティブ画像・商品テキストのembeddingを共変量に入れた需要・価格弾力性推定（応用例はマルチモーダル需要分析でランクベース価格弾力性≈-1が感度グリッド上で頑健）。推定の妥当性担保とクライアント向け説明材料。
- **明日試せる最小検証**：過去の価格/A/Bデータに画像・テキストembeddingを共変量に入れたDMLと入れないDMLを回し、表現の入れ替えで推定値が感度グリッド上どこまで動くかを確認（2日）。
- **落とし穴**：コード・データ公開の明記なし（再現は自前実装）。表現誤差の積の小ささ自体は実データでは直接検証できず、感度分析の読みに習熟が必要。

### [広告クリエイティブ生成] When Text-to-Image Helps Editing: The Effects of Conditioning During Denoising
- **arXiv**：[2610.01681](https://arxiv.org/abs/2610.01681) / 2026-10-01 / cs.CV
- **何が新しいか**：統合編集モデルは編集全区間でソース画像条件付けを続けるのが標準だった。ソースへのアテンションが減衰する編集（背景差し替え・追加系）では、軌跡の途中区間をT2Iモード（VLMキャプションのみ）に切替えて戻すと品質が上がり保持はほぼ不変。対照実験で利得の源泉は「ソース画像の除去」であることを特定（プロンプト改善だけでは知覚品質は上がらない）。
- **検証済みの数字**：FLUX2-Klein 4B/9B・BAGELの3モデル×4ベンチ（GEdit/ImgEdit/MagicBrush/GIE-Bench）で品質6指標すべて改善（例: 4BのGEdit SC 7.72→8.08、GIE-Bench機能正答73.40→76.46）。GPT判定の保持は最大0.16pt低下で非有意。学習なし・重み不変・追加コストはVLMキャプション1回。コード公開。
- **使いどころ**：クリエイティブ制作のリテッチ・差し替え工程。修正初稿の遵守率と見た目の自然さ向上、修正サイクル短縮。
- **明日試せる最小検証**：公開コード（github.com/pbnc5r6/conditioning-switching）でFLUX2-Kleinに区間[10,16)を適用し、自社の差し替え課題20件を純編集と盲検比較（半日）。
- **落とし穴**：SSIM等ピクセル指標は有意に低下する（微小な平行移動でSSIMは鋭く落ちるため）。保持要件が厳しい納品ではアテンション閾値のselective適用を使う。保持評価はVLMジャッジで、人間の知覚との整合は未検証。

### [広告クリエイティブ生成] Soundwich: Video Generation with Layered and Controllable Audio
- **arXiv**：[2610.00691](https://arxiv.org/abs/2610.00691) / 2026-09-30 / cs.CV, cs.MM, cs.SD
- **何が新しいか**：音声同期動画生成はミックスされた単一トラックしか出せず、実務の音声ワークフロー（セリフ・音楽・SE・環境音を個別トラックで管理）と齟齬があった。凍結モデルのまま複数の同期・個別編集可能なstemを生成し、共有シーン表現でstem間の文脈整合を担保。stem単位でリタイム・ミュート・差し替え・リミックスが可能。
- **使いどころ**：動画広告の音声制作・多市場展開。BGM/ナレーション差し替えの版管理を生成段階から分離（版管理工数の削減）。
- **明日試せる最小検証**：公開コード（github.com/CodyNing/Soundwich）で1プロンプトから4 stemを生成し、BGM差し替えとリタイムが破綻なく効くか確認（半日）。
- **落とし穴**：凍結「統合音声動画モデル」前提（TTS+BGMを後段合成する現行パイプラインには直接適用できない）。人手評価で時間制御・分離・自然性の改善を示すが、stem別の定量精度は本文確認要。

### [広告クリエイティブ生成] Do MLLM Judges Judge the Edit? Auditing Bias in Image Editing Evaluation with Verified Quality Preservation
- **arXiv**：[2610.01670](https://arxiv.org/abs/2610.01670) / 2026-10-01 / cs.CV, cs.LG
- **何が新しいか**：VLM判定器のバイアス測定は「介入自体が評価対象の品質を変えてしまう」ため帰属が曖昧だった。品質保存を較正バリデータ・対照・人手検査で保証した反実仮ベンチ（1,196実サンプル・13キュー・4注入位置）を構築し、判定シフトを各判定器自身のノイズフロア（ゼロではなく再質問揺らぎ）と比較する監査を確立。
- **検証済みの数字**：でっち上げの多数意見で評価が上昇、無関係な視覚要素が画像全体操作より大きなシフト、候補順の入替えでペア判定の最大60.9%が反転、編集領域キューは人間一致率も低下。5判定器すべてが自らのノイズフロアを超えるシフトを示す。
- **使いどころ**：クリエイティブ自動検品・コンペ評価のVLMジャッジ運用。候補順固定・多数意見のプロンプト注入禁止・ノイズフロア基準の導入。
- **明日試せる最小検証**：自社のVLM検品プロンプトに候補順入替えと多数意見追加を注入し、判定反転率を再質問揺らぎと比較して測る（半日）。
- **落とし穴**：命令ベース画像編集ドメイン限定。ノイズフロアの計算手順の実装が必要。コード公開の明記なし。

### [エージェント制御] Worse Together: How Performance Breaks Down in Multi-User Multi-Agent Teams
- **arXiv**：[2610.00583](https://arxiv.org/abs/2610.00583) / 2026-09-30 / cs.AI
- **要点**：ユーザごとにエージェントを1体ずつ立てる編成は、共有リソース（計算予算・カレンダー・共同注文・マージキュー）上で単一コーディネータより全4環境で劣る（フロンティア5モデル×77シナリオ）。通信chがなければ2環境で完全崩壊、あっても停滞・相互上書き・虚偽主張という崩壊パターンが残る。緩和策（チームリード等）は環境固有。
- **使いどころ**：社内エージェント展開の設計原則。共有リソースを扱う業務にはユーザ別エージェント群でなく調整役1体を置く。

### [エージェント・ハーネス設計] Finding the Right Fit: Model-Harness Interactions across Agent Tasks
- **arXiv**：[2610.00917](https://arxiv.org/abs/2610.00917) / 2026-10-01 / cs.AI, cs.SE
- **要点**：66構成（4ハーネス×5モデル+ネイティブ2）の統制評価で、モデル順位がハーネス間で反転（Terminal-Bench 4でClaudeはOpenHandsではGPT+7.94pt、PIでは-30.16pt）。自社ベンダーのハーネスが最善とは限らず、高コストが高スコアを保証しない。失敗をモデルが使える形で返すかが適合を分ける。軌跡6,204本と評価コード公開。
- **使いどころ**：エージェント導入のモデル×ハーネス選定。単一ベンチの順位でモデルを決めず、自社タスクでのペア評価を行う。

### [広告クリエイティブ生成] VTR-Bench: A Systematic Benchmark for Evaluating Visual Text Rendering in Video Generation
- **arXiv**：[2610.01499](https://arxiv.org/abs/2610.01499) / 2026-10-01 / cs.CV
- **要点**：動画生成のシーン内テキスト描画を、広告・科学動画などの応用シーン別（5分類・300プロンプト）に測る初の体系ベンチ。キャリア別文字起こしでテキスト忠実度を、シーン・運動要件を分けて評価し、11モデルすべてが苦戦。Keyframe-Guidedエージェント（Director+画像生成+視覚評価の反復）で改善。
- **使いどころ**：動画広告のシーン内文言（看板・パッケージ・テロップ）の検品基準と生成パイプライン改善。

### [広告クリエイティブ生成] Memory-Guided B-Roll Generation from User Video Collections
- **arXiv**：[2610.01884](https://arxiv.org/abs/2610.01884) / 2026-10-01 / cs.CV
- **要点**：動画コレクションから人物・場所・物体・スタイルのentityメモリを構築し、指示に沿ったB-rollを計画・検索・生成する3段システム。非接地プランナー比で視覚整合92.8%勝利、検索のみ編集比では指示遵守94.5%勝利だが視覚整合は58.2%で劣る——生成は「撮れていないショットの補完」に絞るのが正しい使い方。
- **使いどころ**：ブランド footage 資産からのSNS向けB-roll補助生成（実写置き換えでなく補完）。

### [セマンティックレイヤーとオントロジー運用] Argo-Bench: Evaluating Data Agents on Enterprise-Scale Workflows
- **arXiv**：[2610.02122](https://arxiv.org/abs/2610.02122) / 2026-10-01 / cs.CL, cs.AI, cs.DB
- **要点**：text-to-SQLベンチ（表生成のみ・答えキーも誤りがち）を置き換える、企業規模データエージェント評価。8,100万注文のフードデリバリーを235表・75億行のERP倉庫に書き出し、不正アカウント停止・配達員インセンティブ配分・遡及支払いなどの行為をシミュレータ帰結で採点。全タスクに実行可能な参照解。フロンティア14モデル中最強でも95点超えは34.8%。
- **使いどころ**：分析エージェント・ベンダ選定の評価台。クライアント向けエージェント導入前診断の報告書ネタ。
